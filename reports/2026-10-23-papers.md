# Agent & Agent Context 论文日报 · 2026-10-23

## 今日要点
- **KV cache 成为 Agent 上下文管理的新抓手**：Cache Engineering for Agents（AKV）让 agent 直接 drop / 重定位 KV，避免改写前缀后重新 prefill。SARIA 则从服务端优化 DRAM–SSD 缓存复用。
- **记忆走向"原生化"和"执行状态化"**：MemT-1.0 把记忆内化进模型计算，FlowState 把执行状态当作记忆。另有一篇工作指出朴素 Raw-RAG 往往强于复杂 agentic memory。
- **Harness 成为最热话题**：OpenVLHarness、CoEvo-RSI、Self-HPO、HarnessPro、Harness Scaling、Self-Evolving Agent Harness 同时上榜，核心是 harness 与模型如何协同进化。
- **长程任务的上下文折叠开始进入训练目标**：CarryOn（对象化上下文）和 Mosaic（多 session RL）把上下文压缩、子 agent 分叉明确纳入优化。

## 一、🔥 热度榜：Agent Context 精选

### [Cache Engineering for Agents](https://arxiv.org/abs/2610.28577)
- 热度：HF 👍123（入榜 1 天，新增 +14）；代码：[thu-nics/AKV](https://github.com/thu-nics/AKV) ⭐38
- 问题：agent 轨迹增长后，KV cache 的 I/O 与存储成为主要成本；传统的裁剪/摘要会改动前缀，使后续缓存失效并触发重新 prefill。
- 方法：提出 cache engineering，让 agent 通过 `drop`（把选定缓存排除出后续注意力）和 `repos`（调整保留 key 的位置编码）直接控制活跃 KV，而不修改轨迹。论文指出相同 token 序列在不同缓存操作序列下会有不同缓存状态，因此前缀匹配不够，并据此设计了 AKV 服务引擎：对外是无状态接口，内部管理有状态的缓存复用、驱逐与恢复。
- 结论/意义：tool-response 滚动 drop 策略比阈值触发摘要平均分数高 1.7、成本低 27.7%；AKV 吞吐最高 1.2×，P95 延迟加速 1.5×。

### [MemT-1.0: Towards Memory-Native Evolution](https://arxiv.org/abs/2610.26825)
- 热度：HF 👍133（入榜 1 天，新增 +1）；代码：[MemTensor/MemT-1.0](https://github.com/MemTensor/MemT-1.0) ⭐334
- 问题：外部记忆多为被动检索，希望记忆成为基础模型自身的内生能力。
- 方法：基于 Gated DeltaNet-2 在每轮内做稳定的 token 级记忆更新，并用 Mixture-of-Storage 扩展原生记忆容量；经 34B token 的继续预训练 + 后训练，发布 Nano 和 Flash 两个模型。通过内化检索到的过程性经验来提升 agent 任务。
- 结论/意义：在 128K 历史下，MemT-1.0-Nano 相对全上下文 KV cache 端到端推理加速约 1.86×，持久存储减少 66×，记忆能力优于参数化记忆基线，与检索增强方法相当。

### [OpenVLHarness: Real World Visual Agentic Tool-Use with Multimodal Memory](https://arxiv.org/abs/2610.26860)
- 热度：HF 👍112（入榜 1 天，新增 +1）；代码：[uclanlp/OpenVLHarness](https://github.com/uclanlp/OpenVLHarness) ⭐198
- 问题：视觉任务需要多种工具的证据与数值，这些输出必须能被模型读懂并在多步推理中保留。
- 方法：能力层把任务级工具接口与证据渲染结合，把异构工具输出转成模型可读的观察。持久多模态记忆则把图像、结构化数据、网页引用保存为可寻址的 artifact，再配合代码接口对存储数据做跨工具计算。
- 结论/意义：在 22 个基准上，相比无工具基线平均提升 9.7–12.6 分；GPT-6 Luna 中等推理强度下优于最高强度的对照，且模型 token 成本至多为其 37%。

### [FlowState: Execution State as Memory for Long-Horizon LLM Agents](https://arxiv.org/abs/2609.34565)
- 热度：HF 👍21（入榜 1 天，新增 +3）；无代码仓库
- 问题：保留完整历史成本高，压缩又会丢失之后才显现相关性的细节。
- 方法：把执行状态当作记忆，保存带语义类型的状态节点、关系，以及指向原始工具观察的引用，将持久保留与按需访问分离。ISU 在每轮增量更新当前状态，PSA 在推理过程中按需逐步展开历史状态与证据。
- 结论/意义：相对同模型全上下文基线，MemoryArena 成功率 +4.55、τ³-Bench 通过率 +13.95 个百分点，总 token 消耗分别下降 43.2% 和 40.6%。

### [MemPilot: Orchestrating On-Demand Multimodal Memory Curation for LLM Agents](https://arxiv.org/abs/2610.06830)
- 热度：HF 👍36（入榜 1 天，新增 0）；代码：[ViktorAxelsen/MemPilot](https://github.com/ViktorAxelsen/MemPilot) ⭐6
- 问题：多数 agent 记忆在构建时不看查询，既有预处理开销，又可能丢掉后来才重要的细节。
- 方法：用 RL 训练多步策略，迭代地选择"从查询无关记忆检索"或"把原始多模态历史的查询相关整理委派给不同 LLM/VLM"。策略联合控制证据量、整理指令、模型选择和视觉访问，并用目标级优势解耦和前缀边际效用估计做信用分配。
- 结论/意义：在五个多模态记忆基准上，不同偏好下的性能–成本–延迟前沿比现有权衡感知基线更宽。

### [Socratic Skill Learning: Interleaving Teaching and Practice for Transferable Agent Skills](https://arxiv.org/abs/2610.17860)
- 热度：HF 👍32（入榜 1 天，新增 +2）；代码：[NJU-LINK/Socratic-Skill-Learning](https://github.com/NJU-LINK/Socratic-Skill-Learning) ⭐2
- 问题：成功完成一次任务未必能验证技能的适用条件，难以学到可迁移的 Skill。
- 方法：Educator 引导探索，Student 是唯一的环境操作者和 Skill 作者，可以质疑、测试和修改建议。作者构建了 SkillTransferBench（35 个任务族、408 个可执行用例）。Issue-Guided SSL 还会跟踪跨 Skill 版本的未解决问题，用来选择和聚焦评审。
- 结论/意义：主队列上 Fixed-Window SSL 效用 0.801，高于无 Skill 的 0.723；Issue-Guided SSL 达到 0.805，Educator token 少 61.7%。

### [DeLoop: Repeated Actions as Self-Supervision for Long-Horizon Agents](https://arxiv.org/abs/2610.19376)
- 热度：HF 👍19（入榜 1 天，新增 +2）；代码：[cskyl/deloop](https://github.com/cskyl/deloop) ⭐0
- 问题：agent 会重复发起相同工具调用，历史被压缩后这类循环更常见。
- 方法：以 agent 自己 rollout 中的循环动作为负例，同一轨迹里之后第一个非循环动作为正例，用 DPO 训练，无需任务奖励、标准答案或 LLM 评判。
- 结论/意义：在压缩设置的 CodeGym 上，Qwen3-8B 含循环任务占比从 57.3% 降到 6.1%，每任务步数约为原来的三分之一。

## 五、研究趋势观察
- **缓存/记忆从"检索文本"下沉到"模型与系统层"**：热度榜上的 AKV、MemT-1.0，以及 New 里的 SARIA、DLite，都在直接处理 KV cache 或模型内部状态。AKV 和 MemT-1.0 的摘要都给出了对全上下文 KV 的成本对比。
- **上下文管理在重新被审视**：FlowState、CarryOn 倾向结构化状态或对象来替代原始历史；Raw-RAG 一文和 Skip the Compressor 则表明保留原始信息有时更好。两类结论方向不同，说明哪种形式更优仍取决于任务。
- **Harness 与模型协同进化是工程与论文共同的热点**：CoEvo-RSI、Self-HPO、HarnessPro、Harness Scaling 等都在讨论 harness 的优化与泛化。OpenGCUA、S-Agent 2.0 等也在 Codex / Claude Code 等现成 harness 上做文章。
- **GitHub 星数与 HF 点赞并不完全同步**：MemT-1.0（⭐334）、OpenGCUA（⭐441）、Sage-A1.5（⭐578）、Self-Evolving Agent Harness（⭐334）以及 TokenEconomizer（⭐200）的仓库关注度较高，其中 TokenEconomizer 的 HF 点赞仅 4。
