## 四、观察

- **Harness 插件标准在聚拢。** `dsh` / `dsh-plugin` 标签同时出现在 `rea`、`archify`、`ruflo`、`answer-me-with-html` 等项目中，加上 `deepseek-harness` 本身和 `ds-harness-remote` 这类衍生项目，生态正围绕一个宿主平台形成。
- **本地优先的检索与记忆是上下文方向的主线。** `xerj`、`graphify`、`codegraph` 走本地索引路线，`ai-memory`、`agent-memory`、`claude-mem` 做跨会话记忆。共同点是跨 Agent 通用（Claude Code、Codex、Cursor 等）、通过 MCP 或 Skill 接入。
- **Agent 的管理与隔离需求升温。** `OpenShell`（安全运行时）、`orca`（多个编码 Agent 并行管理）、`magpie`（统一换模型）以及新仓库 `pandacode`、`reason-network` 都在解决"同时跑多个 Agent、可控、可协作"的问题。
- **垂直领域 Agent 里，逆向与安全最突出。** `rea` 的增速远超其他项目，`pentagi`、`ARTEX`、`cloudflare/security-audit-skill` 也都在榜上。
