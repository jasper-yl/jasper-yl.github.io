## 四、观察
- **DeepSeek Harness 正在形成独立的插件生态**：平台本身、免费模型、上下文面板、架构图 skill 和逆向工具都挂上了 `dsh-plugin` 标签，生态在围绕平台长出一层插件。
- **上下文工程分化成三条线**：一是索引（图谱和本地检索），二是压缩（沙箱化输出、代理层压缩），三是记忆（跨 Agent 共享存储）。新项目大多强调本地、免 API Key 和多 Agent 通用，而不是绑定单一宿主。
- **Skills 的跨宿主分发已成共识，流量来自"行为型" skill**：增速最高的 skill 多是方法论或流程类（安全审计、YAGNI、美术指导），而不是工具包。官方目录（Anthropic、Cursor）和 `npx skills` 这类分发工具也在同步增长。
- **多 Agent 并行管理、交接和监控工具增多**：orca、harp、coucou、sno-station-skills、reason-network 都是为了在同一台机器或团队内同时管理多个编码 Agent。
