## 今日要点
- 记忆与检索是今天热度榜 Agent Context 的主线。[RAG Compositionality](https://arxiv.org/abs/2610.29722) 发现单项有效的 RAG 技术叠加后收益缩水：三项检索技术预测 +47%，实际只有 +17%。[MCCL](https://arxiv.org/abs/2610.29357) 主张用能否改进未来行动来评判记忆。[MemPilot](https://arxiv.org/abs/2610.06830) 用 RL 学习按需整理记忆。
- Harness 自进化继续升温。热度榜上有 [Self-HPO](https://arxiv.org/abs/2610.22791)（harness 与策略交替优化）和 [HarnessPro](https://arxiv.org/abs/2610.26770)（在性能和成本之间做 Pareto 优化）。新论文 [RSIHub](https://arxiv.org/abs/2610.32253) 把 AHE、Hyperagents、A-Evolve、GEPA 放进同一个框架比较。
- Skills 的学习与复用成为独立方向。[Socratic Skill Learning](https://arxiv.org/abs/2610.17860) 用教师与学生交替的方式学 Skill。昨晚公布的 [LeafSkill](https://arxiv.org/abs/2610.32412)、[CASE](https://arxiv.org/abs/2610.32481)、[MemCryst](https://arxiv.org/abs/2610.32295) 都在做外挂的 Skill 库。
- 新论文开始评测模型与 harness 的交互，以及工具故障下的鲁棒性。[When Agents Fail](https://arxiv.org/abs/2610.32483) 发现不同 harness 的排名随模型和基准而变。[MCP-Injector](https://arxiv.org/abs/2610.32555) 发现模型从 20B 放大到 120B，容错并没有更好。
- 今日点赞最高的 [MJev-Spatial](https://arxiv.org/abs/2610.22276)（👍414）本质是空间理解分类模型，与 Agent 关系弱，不选入精选。

### [Retrieval Augmented Generation Compositionality](https://arxiv.org/abs/2610.29722)
- 热度：HF 👍54（入榜 4 天，新增 +29）；代码 [dolev31/lasagna](https://github.com/dolev31/lasagna) 20★
- 问题：RAG 流水线里的各项技术（embedding、chunking、检索、重排、query 扩写、上下文压缩、agentic 验证）都是单独评测的，叠加后收益是否保留并不清楚。
- 方法：提出开源框架 LASAGNA 做受控评测，预先声明 3 个假设，测了 450 种配置、8 个基准，语料规模 5K–200K 文档。
- 结论/意义：三项检索技术预测合计 +47%，实际叠加只有 +17%；检索质量与回答忠实度的最优组合不同，优化一个可能伤害另一个；语料变大后最优组合也会变。作者呼吁新 RAG 技术要放进完整流水线里测。

### [Memory-Centric Continual Learning for AI Agents](https://arxiv.org/abs/2610.29357)
- 热度：HF 👍43（入榜 4 天，新增 +24）；无代码仓库
- 问题：外部记忆多被当成被动检索缓存，只看能否召回事实，不看能否带来持续学习。
- 方法：提出 MCCL。三轴分类按状态存在哪里（substrates）、什么形态（assets）、如何管理（policies）划分记忆；评测协议衡量干扰下的保留、对变化的适应和任务迁移，以区分真正的行为收益与单纯的上下文扩张；记忆规模化框架建模性能如何随经验、存储容量和算力变化。内层循环更新记忆状态，外层循环根据任务反馈改进管理策略。
- 结论/意义：记忆应该用「是否改进未来行动」来评判。这是立场/综述型论文，摘要里没有实验数字。

### [MemPilot: Orchestrating On-Demand Multimodal Memory Curation for LLM Agents](https://arxiv.org/abs/2610.06830)
- 热度：HF 👍41（入榜 4 天，新增 +5）；代码 [ViktorAxelsen/MemPilot](https://github.com/ViktorAxelsen/MemPilot) 7★
- 问题：多数 Agent 记忆在写入时就按与查询无关的方式构建，既有预处理开销，又可能丢掉后来才发现重要的细节。
- 方法：用 RL 训练一个多步策略，每步二选一：从与查询无关的记忆中检索，或把原始多模态历史交给不同的 LLM/VLM 做针对查询的整理。策略同时控制证据量、整理指令、模型选择和是否查看图像。训练时对每个目标分别估计优势再聚合，并用前缀边际效用估计做多步信用分配。
- 结论/意义：在 5 个多模态 Agent 记忆基准上，性能-成本-延迟的权衡前沿比现有权衡感知基线更宽。

### [Socratic Skill Learning: Interleaving Teaching and Practice for Transferable Agent Skills](https://arxiv.org/abs/2610.17860)
- 热度：HF 👍49（入榜 4 天，新增 +19）；代码 [NJU-LINK/Socratic-Skill-Learning](https://github.com/NJU-LINK/Socratic-Skill-Learning) 2★
- 问题：一次成功的任务尝试可能没有检验 Skill 的适用条件，学出的 Skill 不一定能迁移。
- 方法：SSL 让专家 Educator 的教学与 Student 的实践交替进行。Student 是唯一操作环境、也是唯一撰写 Skill 的角色，可以质疑、测试并修改建议。作者构造了 SkillTransferBench（35 个任务族、408 个可执行用例）检验复用效果。改进版 Issue-Guided SSL 跟踪跨 Skill 修订的未解决问题，用来挑选并聚焦评审。
- 结论/意义：主 cohort 上 Fixed-Window SSL 效用 0.801，无 Skill 为 0.723，Trace2Skill 为 0.761，SKILL-KD 为 0.751。Issue-Guided SSL 达到 0.805，Educator token 少 61.7%，总获取 token 少 16.9%。

### [Building AI Research Teams for Autonomous Discovery of Linear Attention Architectures](https://arxiv.org/abs/2610.28887)
- 热度：HF 👍45（入榜 4 天，新增 +29）；无代码仓库
- 问题：多个 AI 研究员协作时，如何在有限实验预算下互相借鉴发现，同时避免过早陷入局部最优。
- 方法：构建一支持久的 AI 研究员团队，每人有不同学科背景，保留各自的私有研究历史，共享实验证据，并通过自适应分配获得研究机会。
- 结论/意义：用这支团队搜索线性注意力架构，在 1.3B 规模的语言建模、常识推理和合成与真实检索任务上超过 GDN2。消融中去掉任一组织组件都明显变弱：去掉学科背景则搜索早早停滞，去掉私有历史则进展变少，均匀选择不如自适应分配。

### [DLite: History-free Speculative Decoding for Agentic AI](https://arxiv.org/abs/2610.23787)
- 热度：HF 👍36（入榜 3 天，新增 +3）；代码 [SJTU-DAI-Sys/DLite](https://github.com/SJTU-DAI-Sys/DLite) 49★
- 问题：Agent 负载的上下文又长又不断演化，现有投机解码的草稿模型接受长度最多下降 80%，而保留草稿模型的历史 KV cache 又带来很大的系统开销。
- 方法：DLite 把不断增长的历史上下文识别为这两个问题的共同来源，直接复用目标模型的上下文隐状态，只做局部投机预测，不显式维护历史。一个轻量顺序头恢复块内因果依赖，并配套两阶段训练。
- 结论/意义：在通用、长上下文和 Agent 负载上接受长度为 2–6，比最强的投机解码方法 DSpark 高出最多 70%。

### [DeltaStreamer: Towards Human-Like Agentic Streaming Video Understanding](https://arxiv.org/abs/2610.19849)
- 热度：HF 👍38（入榜 3 天，新增 0）；代码 [BBBBchan/DeltaStreamer](https://github.com/BBBBchan/DeltaStreamer) 87★
- 问题：流式视频理解要在不知道未来问什么的情况下保留证据，而现有压缩会模糊事件转折、丢掉细节，且无法找回。
- 方法：在查询到来之前持续观察视频流，把视觉变化显式写入结构化的「变化感知记忆」。查询到来后，由查询驱动的规划器确定所需证据，指导记忆检索和对历史帧的定向回放。
- 结论/意义：OVO-Bench 总分 66.07%，StreamingBench 总分 59.53%，均优于有代表性的流式视频方法。

## 🆕 New：昨晚新公布
- [MemCryst: Lifelong Context Adaptation through Bidirectional Memory-Skill Learning](https://arxiv.org/abs/2610.32295)：冻结模型，让记忆和 Skill 双向学习：记忆里反复出现的片段催生或修订 Skill，Skill 引导的交互再产生新记忆，任务结果调整被检索记录的后续权重。ALFWorld 上联合使用成功率 63.17%，只用记忆 59.83%，只用 Skill 50.50%。代码 [tianyi0216/Memcryst](https://github.com/tianyi0216/Memcryst)。

- [Tool-Calling LLM Agents Under Realistic MCP Faults](https://arxiv.org/abs/2610.32555)：MCP-Injector 是协议感知的故障注入中间件，故障分布取自 1,774 个 MCP 仓库的 57,240 条 issue/PR。注入故障后任务完成分从 8.08 掉到 3.23（−60%），20B 与 120B 的容错没有显著差别，不同 Agent 框架之间的差异更大。
- [LeafSkill](https://arxiv.org/abs/2610.32412)：为递归 Agent 加一层外部复用，检索叶子级动作 grounding 经验，由 1.7B 选择器决定直接使用还是交回原 Agent。Robotouille 200 个任务上成功率 68.5%，ReCAP 为 60.5%，在两者都完成的任务上 token 少 14.42%。
- [CASE: Confusion-Aware Skill Evolution for Frozen Multimodal Emotion Models](https://arxiv.org/abs/2610.32481)：为多模态情绪识别维护稀疏、自进化的「相近情绪对」Skill 库，推理时检索对应 Skill，骨干保持冻结。Qwen3-VL-8B 在 CA-MER 上从 46.80% 提到 59.13%。

- [HiSTEVE 1.0](https://arxiv.org/abs/2610.31162)：Minecraft 里的分层 VLA Agent，harness 带用于追踪进度的结构化记忆和 VLM 规划器，MineStudio Bench 得分 85.0%，OpenHA 平均成功率 37.4%（初步 👍37）。
- [4DMemory](https://arxiv.org/abs/2610.32332)：约 900 小时视频、5,000+ 题的长程时空记忆基准，配套 4DMemory Harness（4 类 Skill、22+ 工具模型、检索增强），让 13 个模型都提升 50% 以上；同一批模型在新基准上比旧基准低 10% 以上。
- [DraMaze](https://arxiv.org/abs/2610.32002)：微短剧剧本生成的多 Agent 流水线，用「后向叙事依赖树」按未来剧情目标组织和检索历史记忆。60 集剧本上因果模式重复降低 32.1%，Logic 分 82.5，比最佳基线高 8.5 分（初步 👍8）。

## 研究趋势观察
- 记忆研究正从怎么存、怎么检索，转向怎么评判和怎么按需整理。MCCL 提出看是否改进未来行动，MemPilot 把整理做成可调的性能-成本-延迟策略，RAG Compositionality 提醒单项收益不能直接相加。新论文 [ActionRAG](https://arxiv.org/abs/2610.32752)、[MemCryst](https://arxiv.org/abs/2610.32295)、[Agentic Memory Management](https://arxiv.org/abs/2610.32464) 同样围绕记忆。
- Harness 自进化在热度榜和新论文两端都有。hot 里有 [Self-HPO](https://arxiv.org/abs/2610.22791)、[HarnessPro](https://arxiv.org/abs/2610.26770)、[Terminal-RSI](https://arxiv.org/abs/2610.22192)，rising 里有 Self-Evolving Agent Harness，昨晚新出 [RSIHub](https://arxiv.org/abs/2610.32253) 和 [When Agents Fail](https://arxiv.org/abs/2610.32483)。Self-HPO 的联合增益超过单独增益之和，RSIHub 则发现优化收益不一定迁移，两篇适合对照着读。
- Skills 作为外挂的上下文资产被越来越多地研究：[Socratic Skill Learning](https://arxiv.org/abs/2610.17860)、[LeafSkill](https://arxiv.org/abs/2610.32412)、[CASE](https://arxiv.org/abs/2610.32481) 都让 Skill 库独立于模型参数。工程侧可对照的是 OpenGCUA（441★）、Self-Evolving Agent Harness（387★）、[simple-agent-lab/RSIHub](https://github.com/simple-agent-lab/RSIHub)（198★）这类开放 harness/框架项目的星数。
- 环境与基准合成仍是 Agent 其他方向的主流：[CoworkEnv](https://arxiv.org/abs/2610.24960)、[Interlock](https://arxiv.org/abs/2610.19686)、MAI-Gym、[AdaExploreBench](https://arxiv.org/abs/2610.25950)、[OR-License](https://arxiv.org/abs/2610.24087) 都在解决如何得到可验证的训练或评测任务。多数评测结论是差距仍然明显，例如 OR-License 中无模型追平专家。
