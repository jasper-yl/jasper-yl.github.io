## 热度榜：Agent Context 精选

### [Rare, Relevant, and Still Wrong: How Memory Fails LLM Group Decisions](https://arxiv.org/abs/2610.37624)
- 热度：HF 👍8（入榜 6 天，新增 +4）；无代码仓库
- 问题：多个 LLM 的讨论被压缩成一段短记忆交给最终决策者时，该保留什么？
- 方法：提出诊断基准 CrossProfile（60 个模板，480 个任务），让「支持、干扰、无关」事实的归属交叉变化而文本不变。对比按相关性保留和按稀有度保留两种启发式，测试模型有 Qwen2.5-7B、Llama-3.1-8B 和两个 DeepSeek 模型。
- 结论/意义：两种启发式都会失败。相关性筛选会把干扰项放回来，因为干扰项也「切题」；即使是完美的相关性过滤器，在经典 hidden-profile 配置下也比「稀有优先」低 23–31 分。稀有优先平均不比随机好。决策模型对多个 Agent 共同持有的事实有「社会认同」偏差，去掉归属标签后准确率提升 13–24 分。在自然讨论中，完整转录的准确率反而低于完全没有笔记。

### [MemSteer: Turning User Histories into Supervision for Agent Memory Optimization](https://arxiv.org/abs/2610.39276)
- 热度：HF 👍6（入榜 4 天，新增 +6）；无代码仓库
- 问题：新用户的历史没有标注，很难优化 Agent 记忆设计。
- 方法：MemSteer 把未标注的用户历史转成带证据的问答监督：先构造「证据支撑的答案计划」，再生成问题，并用来源审计和盲答恢复检验标注。配套的 MemSteer-Opt 用问答评估加失败诊断，修改记忆的存储、检索和上下文构造，不更新模型参数。
- 结论/意义：相对 Base-BM25，ATM-Bench Question Score 提升 13.4 分，RHELM 准确率分别提升 4.1（不用外部数据）和 6.6（用外部数据），与官方问答监督引导的优化效果相当。

### [Your Policy Is Secretly a Harness: The Decision Geometry of Agent Interfaces](https://arxiv.org/abs/2610.37255)
- 热度：HF 👍8（入榜 6 天，新增 +2）；代码 [2020-qqtcg/HRP](https://github.com/2020-qqtcg/HRP) ⭐1
- 问题：模型在某个 harness 下训练后，学到的东西换 harness 还能保留多少？
- 方法：在 KL 正则化控制下证明，最优策略的 log odds 能还原其 harness 对各动作的偏好。部署回报等于 harness 的「天花板」减去策略的「失配」；训练只改变失配，换 harness 则两项都变。所以固定模型比较 harness，会把「harness 提供什么」和「模型用得好不好」混在一起。
- 结论/意义：在 MiniWoB++ 上，仅把观测字段顺序反过来（最优决策不变），训练后模型的成功率从 85.0% 掉到 19.2%。在 Terminal-Bench Lite 上，用更强模型估计「天花板减失配」能复现准确率排名，单看任一项则不行。

### [Rethinking Verification in Agent Harnesses](https://arxiv.org/abs/2610.34577)
- 热度：HF 👍7（入榜 6 天，新增 -2）；无代码仓库
- 问题：harness 里的验证环节该怎么组织？
- 方法：覆盖 Agent 生命周期的四层：初始指令、执行中提醒、完成门控、独立评审。在 7 个前沿编码模型上对比 17 种设计，基准为 Terminal-Bench 和 SWE-bench Verified，并新增 VisualBench。
- 结论/意义：初始指令和执行中提醒的收益较小，且依赖具体模型；完成门控收益可能更大，但成本明显增加；独立评审性价比最好，Terminal-Bench 准确率提升 5.9–9.5 个百分点，成本为基线的 1.13–1.25 倍，SWE-bench 提升 3.9–6.6 个百分点，成本为 1.00–1.04 倍。

### [Skill^{infty}: Recursive Self-Improvement for Agent Skill Optimization](https://arxiv.org/abs/2610.35434)
- 热度：HF 👍8（入榜 7 天，新增 +5）；代码 [taowangcheng/Skill-Infinity](https://github.com/taowangcheng/Skill-Infinity) ⭐6
- 问题：现有技能优化器的流程靠手工设计，元技能被固定在一条流水线里，而且每个任务都要重新学。
- 方法：元 Agent 按「元技能」优化任务技能，同时用同一流程优化元技能本身。元技能与任务技能解耦，在多个优化任务上打磨后再复用到其他领域。两层技能都是标准技能包，通过原生技能发现机制加载。
- 结论/意义：在 83 个 SkillsBench 任务上通过率 60.7%，人工技能为 56.4%，SkillEvolver 为 54.5%。

### [R^2Orch: Recursive Self-Improvement for Agent Orchestration via Self-Play within a Skill-Internalization Loop](https://arxiv.org/abs/2610.22740)
- 热度：HF 👍49（入榜 1 天；首次出现时为 85，现为 49，新增 -36，点赞波动较大）；代码 [beita6969/R2Orch](https://github.com/beita6969/R2Orch) ⭐12
- 问题：编排学习依赖手工课程，rollout 结果相同时优势信号会塌缩，技能评估的信号噪声大。
- 方法：内层自博弈在 Proposer 自选的任务上改进编排器，外层改进内层的改进方式。技能撤回（Skill Withdrawal）的做法是：对照评估显示不用某技能编排器表现相同时，就撤掉该技能。失败被蒸馏成技能，技能被蒸馏进参数，编排器逐步趋向「零技能部署」。
- 结论/意义：在 12 个数据集（问答、数学、代码、交互任务）上持续优于基线。

### [RoboArchitect: Automating the Design of Robotic Agents with Persistent Memory](https://arxiv.org/abs/2610.42141)
- 热度：HF 👍7（入榜 1 天，新增 +2）；代码 [roboarchitect-ai/RoboArchitect](https://github.com/roboarchitect-ai/RoboArchitect) ⭐3
- 问题：冻结的机器人策略放进 harness 后效果好得多，但 harness 都是为每个机器人或基准手工重做的。
- 方法：编码模型观察 rollout、诊断失败，迭代修改冻结策略之外的 harness。harness 还会演化出自己的持久记忆，把学到的经验（例如有效抓取深度）带入后续决策。
- 结论/意义：不更新任何权重，未见场景平均成功率从 9.7% 到 43.3%（4.5 倍），未见任务从 12.7% 到 40.2%（3.2 倍）。

### [Matched Capabilities, Different Behaviors: A Controlled Study of MCP and CLI Interfaces for Language Agents](https://arxiv.org/abs/2610.34298)
- 热度：HF 👍5（入榜 7 天，新增 +5）；代码 [ModalityDance/MICA](https://github.com/ModalityDance/MICA) ⭐0
- 问题：MCP 和 CLI 暴露相同的语义操作时，Agent 行为是否相同？
- 方法：MICA 用同一份语义动作契约渲染 MCP 和 CLI，走同一个运行时，在 6 个模型、3 个交互环境里比较。再提出 DART，保留已验证的语义决策，只修复接口相关的动作实现。
- 结论/意义：接口匹配也会造成任务表现和交互成本的差异，2,004 个轨迹中 94.3% 出现结构性分歧。DART 在 6 个设置里全部提升分数，最多 +9.0；在 3 个环境里降低 MCP token 成本，最多每任务 27.1k tokens。

- [Parallelism-Aligned Pruning and Round-Aware Context Reuse (PARC)](https://arxiv.org/abs/2611.02601)：面向端侧多模态 Agent，按生命周期重组 KV 缓存，让历史图像不再留在持久缓存中，同轮次预算下能容纳更多交互轮数。七核部署下解码吞吐提升 23.8%。
- [Pulse: Long-Horizon Tasks Need Streaming Personalization](https://arxiv.org/abs/2611.00988)：独立的轻量记忆 Agent 在执行期间持续监控，用 RL 学习何时、如何介入。π-Bench 71.9%，MCP-Persona 46.4%，均为对比方法中最高。
- [MemHarmBench: Evaluating Cross-Session Prompt Injection in Memory-Persistent AI Agents](https://arxiv.org/abs/2611.01700)：评测恶意指令被写入持久记忆后，在后续正常会话中影响决策。多个 Agent 系统在完成任务且无异常迹象的同时，仍做出符合攻击者意图的决策。

## 研究趋势观察
- 热度榜（过去 1–7 天）集中在 harness 上：验证设计（2610.34577）、策略与 harness 的耦合（2610.37255）、harness 自动设计与记忆（[roboarchitect-ai/RoboArchitect](https://github.com/roboarchitect-ai/RoboArchitect)）、接口表示（MCP 与 CLI，[ModalityDance/MICA](https://github.com/ModalityDance/MICA)）。new 里的 TinyAstral 和 Continual Harness Evolution（2611.03219）延续这一方向，后者报告 Meta-Harness 在 SWE-Bench 上从 94.0% 在后续演化中降到 32.0%（第五轮）。
- 记忆与压缩研究的关注点从「存多少」转向「存对了没有」：CrossProfile 的筛选失败、ARCBench 中规则在摘要里却仍被违反、StateGraph 的依赖修订、AC3 的上下文污染，结论互相印证：信息保留不等于被正确使用。
- Skills 与自我改进是并行主线：Skill^∞、R²Orch（hot），Zep Agent Skills、CUA-Master、NorthCUA（new），多数以「递归自我改进（RSI）」为表述。
- 推理服务侧开始针对 Agent 工作负载单独研究：metastability、Fairway、PARC、Jet-QSparse、SIMPLE 能耗定律（agentic 请求能耗是非 agentic 的 13.0 倍，前缀缓存后仍是 4.8 倍）。这些论文多数没有 GitHub 仓库，数据中看不到工程侧的呼应。
