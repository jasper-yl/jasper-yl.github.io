### [Gamer: A Generalist Vision-Language-Action Foundation Model for Long-Horizon Real-Time Game Agent](https://arxiv.org/abs/2611.18397)
- 热度：HF 👍116（入榜 1 天，新增 +30）；代码 [RainBowLuoCS/Gamer](https://github.com/RainBowLuoCS/Gamer) ⭐243（11-16 日报时 ⭐124）；无 X 数据。11-16 日报已作为 new 报道（👍86）。
- 问题：长程、实时的游戏和 GUI 任务中，有限的上下文窗口、累积误差和稀疏奖励让 Agent 难以持续运行。
- 方法：端到端架构把感知、记忆管理和多步推理放在一起。先用数万小时键鼠交互数据继续预训练，再做稀疏思考指令微调以减少冗余推理；随后用稳定的多轮 RL 训练长程交互，明确针对有限上下文窗口。云边推理引擎支持「无界上下文执行」。
- 结论/意义：在多个 3D 开放世界游戏上泛化良好，效率可比熟练玩家，在 2D 游戏基准上有竞争力。摘要没有给出记忆机制的细节。

### [Envisioning Agentic Robotics: A New Era of Robotic Systems](https://arxiv.org/abs/2611.18359)
- 热度：HF 👍123（入榜 1 天，新增 +16），热度榜第一；无代码。11-16 日报已作为 new 报道（👍107）。
- 问题：agentic 机器人还没有共同定义、可靠的评测框架和研究路线。
- 方法：提出「具身 System 2」，即基础模型加具身 harness 作为决策核心。harness 内的闭环依次是观察、理解意图、推理、调用 skills 与工具、验证结果、调整策略。论文还给出同时衡量模型能力和闭环系统表现的评测框架，并总结哪些原则可从数字 Agent 迁移到物理 Agent。
- 结论/意义：给出面向「持续自主」的路线图，从执行单个原语到承担常设角色。这是一篇愿景论文，没有实验数字。

### [Continual-ARC: Measuring Skill Acquisition over a Working Lifetime](https://arxiv.org/abs/2611.14505)
- 热度：HF 👍10（入榜 1 天，新增 +1）；代码 [unifyai/continual-arc](https://github.com/unifyai/continual-arc) ⭐37。
- 问题：现有持续学习基准多为单领域、每个实例只出现一次，记忆型和权重型系统无法放在同一尺度上比较。
- 方法：用三个 ARC-AGI 版本构成终身任务流，同样的任务隔一段时间换新实例再出现。学习者可以付费查看演示、提交答案或在 harness 里行动，按消耗的反馈预算打分。测试时冻结学习者，分别测「见过的任务」（记忆）和「没见过的任务」（泛化）。实验用 Qwen3.5-9B 和 GLM-5.3 Flash 跑有/无持久化的冻结权重 harness，对比两个提示下限、程序归纳方法和模仿训练的权重。
- 结论/意义：除非给出明确的专家指导，harness 持久化一般不提升记忆表现；多数 harness 方法学到的比「只缓存每个任务演示」的下限还少，在未见任务上也没有提升，权重学习则有明显提升。

### [Can LLM Agents Organize Their Own Memory?（SoMem）](https://arxiv.org/abs/2611.11929)
- 热度：来源 arxiv，无 HF 点赞（入榜 7 天）；代码 [Qi202/SoMem](https://github.com/Qi202/SoMem)，数据里无星数。已在 11-10、11-16 日报出现，与 MIRIX-2.0 同日出现，路线不同。
- 问题：固定记录加固定组织规则的记忆，难以适应不断变化的任务。
- 方法：记忆存成互相链接的普通文档，Agent 自己决定摘要什么、怎么归类、何时修订主题，每条摘要都链回原始交互作为证据。运行时校验更新，并自动派生时间、关系、近期三种视图。查询时 Agent 自己选择搜什么、读什么，沿链接回看原始证据。
- 结论/意义：在 LoCoMo、BEAM-100K、LongMemEval-S 上分别比最强基线高 2.66、3.10、2.00 个百分点；记忆可跨模型复用，增加推理投入还能再提升。

### [Review the Episodes, Refine the Lessons: Simple Memory Evolution for Embodied Agents（SimplEvo）](https://arxiv.org/abs/2611.11509)
- 热度：来源 arxiv，无点赞（入榜 7 天）；无代码链接。
- 问题：围绕 MLLM 堆叠的 harness（后训练策略、递归自我改进循环）是否真的超过 MLLM 自身能力，一直没人验证。
- 方法：不更新权重，不用后训练策略，不用特权信息。MLLM 先从一次演示写出一份无坐标的任务记忆，再在训练回合上维护一份有界的工作记忆，每回合后按「流程、完成、恢复」提炼教训。测试时两份记忆固定不变。
- 结论/意义：EBench 上 GPT-6-Astra 直接控制的成功率从 46.7% 升到 81.7%；RoboDojo 榜单第一，SR 69.63%、得分 75.32。纯文本记忆与存过往画面的记忆成功率相近，但 token 更少；GPT-6-Astra 写的工作记忆可直接给较弱的 MLLM 使用并提升其表现。

### [When Should Agents Remember? Falsification-Gated Self-Evolution for LLM Agents（FGSE）](https://arxiv.org/abs/2611.14326)
- 热度：来源 arxiv，无点赞（入榜 6 天）；无代码链接。
- 问题：自我改进常把单个回合得到的教训直接写入记忆，而局部成功并不可靠。
- 方法：每条候选教训写成结构化假设（前提、行为变化、预期效果、验证器）。先只在临时状态中应用它，用目标迁移、证伪、归档回归三类探针检验，再按实测收益和风险决定提交、改进或拒绝。
- 结论/意义：WebArena 成功率 39.8，AppWorld 平均完成度 78.8，τ-Retail / τ-Airline Pass^1 为 0.724 / 0.487；证伪失败降到 5.0%，回归损害 1.3%，有害的已提交更新 3.6%。

### [Verify Before You Fetch: Reliable KV Cache Compression for LLM Inference（VerKV）](https://arxiv.org/abs/2611.11319)
- 热度：来源 arxiv，无点赞（入榜 7 天）；无代码链接。已在 11-10 日报出现。
- 问题：长上下文、长寿命 Agent 的 KV cache 超出显存后会卸载到 CPU，CPU 到 GPU 的传输主导延迟；与查询无关的压缩又很难保证对任意查询都准确。
- 方法：GPU 上放一小组与查询无关的关键 token（用 PoissonComp 随机采样选出），加上整个 KV cache 的 token 级 sketch，完整缓存留在 CPU。推理时 KVFetch 用它们估计注意力的相对误差；满足用户设定的 (ε, δ) 容限就不访问主机内存，否则按查询从 CPU 取回更多 token。
- 结论/意义：32K 上下文、RULER 与 LOFT 平均下达到稠密质量的 90–100%，GPU 显存占用降 8–32 倍，每生成一个 token 的 CPU 到 GPU 取数控制在缓存的 2–23%。

## 研究趋势观察
- 记忆研究的重心从「怎么存、怎么检索」转到「何时该写入、变化时怎么办」：FGSE（证伪门）、EGE（审计后采纳）、LEDGER（事实有效期与删除）、Read Boundaries in Agent Memory（记忆读取一致性）都在管写入与更新的可靠性，HEAMS 还把隐私、删除、投毒抵抗纳入评测。
- 经验不一定有益的证据在增多：Experience Rot（工具变更后经验反而有害）、Continual-ARC（harness 持久化不如缓存演示）、Where Should Agents Adapt（ICL 常跳过验证）。三篇只在「经验/记忆的副作用」这一点上相似，各自结论不能互相套用。
- 上下文与工具成本仍是工程焦点：Beyond Plain MCP（token 降 70–90%）、EfficientSkill（输出 token 最多降 80%）、VerKV（显存降 8–32 倍）、DroidPrefill（固定上下文预算）。
- 今天的输入里没有 GitHub 项目数据，只有论文仓库星数：[Mirix-AI/MIRIX](https://github.com/Mirix-AI/MIRIX) ⭐3488 远高于其他，其次是 [RainBowLuoCS/Gamer](https://github.com/RainBowLuoCS/Gamer) ⭐243、[InfrathonX/Infrathon](https://github.com/InfrathonX/Infrathon) ⭐42、[unifyai/continual-arc](https://github.com/unifyai/continual-arc) ⭐37，其余多在 25 以下。
- 点赞最高的是 Envisioning Agentic Robotics、Gamer、VibePrevisBench、Sage，多为模型、机器人或基准方向；记忆和上下文方向除 MIRIX-2.0 外点赞都很少。
