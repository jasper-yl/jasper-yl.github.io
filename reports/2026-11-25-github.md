## 观察
- 多 Agent 控制层是今天最热的单一方向。榜首两位是 [pingdotgg/t3code](https://github.com/pingdotgg/t3code) 和 [stablyai/orca](https://github.com/stablyai/orca)；腰部有 [herdrdev/herdr](https://github.com/herdrdev/herdr) 稳定增长，[getpaseo/paseo](https://github.com/getpaseo/paseo)、[jiangmuran/vibepanel](https://github.com/jiangmuran/vibepanel)、[jazzenchen/agent-hud-open](https://github.com/jazzenchen/agent-hud-open)、[sun168567/cc-desk-tunnel](https://github.com/sun168567/cc-desk-tunnel) 出现在新秀或次级榜单里。共同点是同时跑多个编码 Agent，并能从手机或远程接入。
- Skills 是 Agent Context 的默认载体，垂直化趋势明显。通用框架（[obra/superpowers](https://github.com/obra/superpowers)、[mattpocock/skills](https://github.com/mattpocock/skills)）存量巨大；今天爆发的是垂直 skills：安全（[elementalsouls/Claude-BugHunter](https://github.com/elementalsouls/Claude-BugHunter)）、合规（[mjmirza/app-store-compliance](https://github.com/mjmirza/app-store-compliance)）、设计（[cathrynlavery/diagram-design](https://github.com/cathrynlavery/diagram-design) 等）。[NVIDIA/SkillSpector](https://github.com/NVIDIA/SkillSpector) 这类「装 skill 前先扫描」的工具连续 86 天稳定增长，生态在补审计环节。
- 「逆向再重建」成了一组反复出现的做法。数据里可见 [morluto/rea](https://github.com/morluto/rea)（逆向任意目标）、JuneYaooo/rea-video（视频逐镜头拆解）、[erkamyaman/rea-games](https://github.com/erkamyaman/rea-games) 和 rust-anything（重写后逐步对照原行为验证）、Jakeschincariol/replica-skill（克隆应用）、NiazMorshed2007/reanimate（逐帧逆向动画）。共同卖点是重建后可验证。
- 数据质量：new_fast_repos 里有 GirishSystems1994/reverso-context、Lukcla3889/postman-agent、kofimehta06/capture-one-23 三个创建 1 天的仓库，星数 105–120，描述是 Windows 软件下载页式文案，topics 堆砌无关关键词，已剔除。
