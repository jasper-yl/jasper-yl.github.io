## 🔥 热度榜：Agent Context 精选

### [Tools Need Not Speak in Text: Latent Context Compression for Agents](https://arxiv.org/abs/2611.06500)
- 热度：HF 👍6（入榜 4 天，新增 +6）；代码 [THU-Agent/Coca-cola](https://github.com/THU-Agent/Coca-cola) ★7；无 X 数据
- 问题：智能体把原始工具输出直接追加进上下文，多步之后冗长噪声增多，稀释注意力；文本层面的剪枝和摘要压缩率有限。
- 方法：Coca-Cola 把工具观察压成连续的隐 token，嵌入智能体的输入 embedding 空间。Action-Preserving Training 让压缩前后的下一步动作分布对齐，使隐 token 保留决策关键信息。
- 结论/意义：在 4 个 QA 基准、两个模型家族的 web 搜索智能体上，token 消耗降 70.01%–89.24%，端到端时间降 24.45%–55.97%，任务表现还持续提升。

### [Adversarial Speculative Reasoning Improves Long Horizon Agents](https://arxiv.org/abs/2611.05345)
- 热度：HF 👍10（入榜 5 天，新增 +6）；无代码
- 问题：推测解码通常只被当作加速手段，但验证窗口内的数值噪声会累积，约 30 步后改变长程智能体的输出分布，影响推理准确率。
- 方法：在智能体轨迹中找出关键推理点，训练 draft 模型在这些点上「故意被拒绝」，让关键思考 token 由目标模型在噪声最小的条件下采样。只训练 0.06%–0.28% 的托管参数，目标模型和输出分布不变。
- 结论/意义：在复杂 agentic 编码基准上提高了端到端成功率；摘要把推测解码重新定位为「上下文精度的分配器」，未给出具体提升数字。

### [SwarmEvolve: Latent Agent Swarms for Evolutionary Discovery and Optimization](https://arxiv.org/abs/2611.08483)
- 热度：HF 👍10（入榜 3 天，新增 +10）；代码 [Qile-J/SwarmEvolve](https://github.com/Qile-J/SwarmEvolve) ★14
- 问题：LLM 引导的进化搜索每轮要生成长文本思维链，还要反复生成以维持种群多样性，速度慢。
- 方法：每轮由数百个低成本智能体并行工作（项目自称 swarm），在隐空间推理而不解码成文本，通过传递 KV cache 共享信息。新颖性过滤器直接用隐状态向量距离保留差异最大的想法；总结智能体接收全体成员合并后的 KV cache，在隐空间完成想法交叉。
- 结论/意义：在 21 个数学发现和科学计算问题上平均分最高；达到其他 SOTA 框架 60 分钟才能达到的最好分数，中位数只需 3–8 分钟；用 Qwen3 8B 在若干问题上改进了 AlphaEvolve 用前沿模型找到的解。

### [The SIMPLE Law for Energy Cost of LLM Inference](https://arxiv.org/abs/2611.03330)
- 热度：HF 👍10（入榜 6 天，新增 +10）；无代码
- 问题：没有解析模型能说明每个 token 的真实能耗，现有 SOTA 是需要逐模型拟合的经验模型。
- 方法：推导覆盖 MHA 和 GQA 的计算与访存复杂度闭式表达，得到四参数的 SIMPLE 模型。模型把 prefill 与 decode 分开，decode 再拆成 KV cache 成本和下一 token 计算。
- 结论/意义：在 13 个稠密 LLM、H100 上 R²=0.969、MAPE 11.97%，比 SOTA 低 3.1–3.5 倍，无需逐模型校准。智能体式服务每请求能耗是非智能体的 13.0 倍；前缀缓存去掉约 93% 的 prefill 成本，但 KV cache 项不受影响，缓存后的智能体请求仍贵 4.8 倍。

### [GEPA-Curator: Curated Learning for Self Improving Agents](https://arxiv.org/abs/2610.37651)
- 热度：HF 👍8（入榜 6 天，新增 +3）；无代码
- 问题：反思式提示优化器（如 GEPA）从失败轨迹中学习，但失败可能来自提示弱点、harness 限制、随机性或噪声评判，未必是有用信号。
- 方法：任务策展负责过滤噪声大、不可靠的任务；先前成功轨迹检索则为任务选择性检索过去的成功轨迹，作为额外上下文交给提示优化器。
- 结论/意义：在 GoBrowse、ALFWorld、AppWorld、τ-bench 上，用 Gemini 3.1 Pro 和 Claude Opus 5 作优化器，持平或超过两个基线的均值，最高比 GEPA 高 20.7%、比 ACE 高 21.2%。

### [Can Large Language Model Agents Learn by Watching Tutorial Videos?](https://arxiv.org/abs/2611.01460)
- 热度：HF 👍5（入榜 6 天，新增 +3）；无代码
- 问题：LLM 智能体的能力训练后即冻结，无法利用海量教学视频，而更新参数的代价太高。
- 方法：Tutorial Agentic Learning（TAL）通过两阶段对抗过程（挖掘视频相关的难题，并用其精炼记忆），把教程视频整合为持久的结构化「tutorialbook」记忆。推理时通过目录（TOC）树检索，让检索与模型推理挂钩，而不靠 embedding 相似度。
- 结论/意义：在由 72 个国际象棋教程视频（12 种开局）构建的 VidLearn 上优于所有基线，随视频增多单调提升，相对原始 MLLM 在训练/测试划分上最高提升 113% 和 91%；实战中 69% 的对局开局局面优于原版。

### [RoboArchitect: Automating the Design of Robotic Agents with Persistent Memory](https://arxiv.org/abs/2610.42141)
- 热度：HF 👍8（入榜 7 天，新增 +3）；代码 [roboarchitect-ai/RoboArchitect](https://github.com/roboarchitect-ai/RoboArchitect) ★10
- 问题：冻结的机器人策略放进 harness 后效果好得多，但 harness 都是为每个机器人和基准手工设计的。
- 方法：编码模型观察机器人 rollout、诊断失败，迭代修改冻结策略外围的 harness，不更新任何模型权重。harness 还会自行演化出持久记忆，把学到的经验（如有效抓取深度）带入后续决策。
- 结论/意义：未见场景平均成功率从 9.7% 提升到 43.3%（4.5 倍），未见任务从 12.7% 到 40.2%（3.2 倍）。

- [Where to Learn and How Far to Roll Out: Efficient Adaptive Training for GUI Agents](https://arxiv.org/abs/2610.39251) · HF 👍4 · 入榜 5 天：GUI 智能体 RL，用关键 pivot 与自适应 rollout 长度，相对 Vanilla GRPO 减少 56–61% 的环境交互，任务表现反而提升。

## 📈 持续升温
- [From Autonomous Agents to Cognitive Symbionts](https://arxiv.org/abs/2611.05376) · 👍 从首次报道时的 40 涨到 120（11-08 日报记为 114）：单作者（Hao Fei）的愿景/位置论文，提出「认知共生体」，即终身、实时、私密、主动的个人伴侣，跨年保存用户上下文；核心概念是「人能带入情境的内容与工作记忆容纳量之间的认知缺口」。摘要只有概念框架、设计空间和治理风险（如考试中的隐蔽辅助），没有实验，无代码。它在总榜点赞第一，但读者应知道这是愿景而非实证（首次报道见 11-07 日报，11-08 日报再次提及）。

- [AgentBaton](https://arxiv.org/abs/2610.35959)：长程任务中从强模型到弱模型的一次性交接（含上下文传递），11 组模型对平均省 65.9% API 成本，准确率基本保持（👍10）。
- [Video-Coder](https://arxiv.org/abs/2611.09894)：训练代码驱动的视频生成智能体，配套 harness 与 SFT+RL（👍11）。
- [Authorization Drift in LLM Agents](https://arxiv.org/abs/2611.09113)：648 样本基准，衡量智能体多步工具调用中的越权；13 个 LLM 上能力越强越易越权（前沿模型漂移率 0.43–0.61），但 86.18% 的任务存在干净的成功轨迹（👍5）。
- [MemoryDojo](https://arxiv.org/abs/2611.09721)：记忆投毒基准，含 155 条多会话轨迹、5 种记忆系统，所有被测记忆系统都易受投毒。
- [Compaction, decay and reinforcement in a two-tier conversational memory](https://arxiv.org/abs/2611.09807)：在 LoCoMo 上对事实压缩与 RAG 做配对评测；四类可比题上 71.4% 对 64.6%，prompt token 少 34%；含对抗题的全部五类则优势缩到 2.0 且不显著。
- [From LoRA to Language](https://arxiv.org/abs/2611.09454)：把已编译进 LoRA 的 Skill 文档写回文本；Executing Writer 恢复并保留 39–44% 的关键指令，在 ALFWorld 上让 Llama-3.1-8B 从 5% 到 55%。
- [Nebula](https://arxiv.org/abs/2611.09474)：分布式位置无关 KV 缓存（PIC）服务框架，在 RAG 与智能体负载上中位 TTFT 平均降 61.4%。
- [DARIC](https://arxiv.org/abs/2611.09109)：位置无关的 KV cache 复用，配合分布感知的重算，TTFT 加速 1.1–4.5 倍；代码 [Lenovo-ICI/DARIC](https://github.com/Lenovo-ICI/DARIC)。
- [From Procedures to Permissions](https://arxiv.org/abs/2611.08905)：用 Agent Skills 中的流程知识监督子智能体授权，工具权限精度 +13.4 点，工作区权限精度 +24.1 点。
- [The Last Mile to the Real World (HEELO)](https://arxiv.org/abs/2611.07461)：用「智能体原生原语」库按任务组装 harness，Terminal-Bench 4.0 从 37.3% 到 55.5%（👍3）。

## 研究趋势观察
- 上下文压缩与缓存是主线：hot 里有 [Coca-Cola](https://arxiv.org/abs/2611.06500)（隐 token 压缩工具输出）、[SwarmEvolve](https://arxiv.org/abs/2611.08483)（KV cache 传递）、[SIMPLE](https://arxiv.org/abs/2611.03330)（KV cache 与前缀缓存的能耗），New 里有 [Nebula](https://arxiv.org/abs/2611.09474) 和 [DARIC](https://arxiv.org/abs/2611.09109)（KV 复用），都在降低长上下文成本。
- harness 自进化的问题从「能不能」转到「靠不靠谱」：hot 的[持续进化遗忘研究](https://arxiv.org/abs/2611.03219)（SWE-Bench 94.0%→32.0%）与 New 的 [Beneath the Surface](https://arxiv.org/abs/2611.07624)（16 个进化智能体有得有失）指向同一点：基准分提升不代表原有能力得到保持。[RoboArchitect](https://arxiv.org/abs/2610.42141) 这类 harness 自动设计仍在推进。
- 记忆研究兼顾取舍与安全：New 里有压缩与 RAG 的配对评测和 [MemoryDojo](https://arxiv.org/abs/2611.09721) 记忆投毒基准；hot 里的 [TAL](https://arxiv.org/abs/2611.01460) 和 [GEPA-Curator](https://arxiv.org/abs/2610.37651) 都把检索过去经验作为不更新参数的学习路径。
