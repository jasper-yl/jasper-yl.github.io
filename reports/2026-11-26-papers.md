### [MMMem: Self-Improving Agents with Task-Aware Multimodal Experience Consolidation](https://arxiv.org/abs/2611.30287)
- 热度：HF 👍10（入榜 2 天，新增 +9）；代码 [ChenYX24/MMMem](https://github.com/ChenYX24/MMMem) 0 星
- 问题：多模态长期记忆多半只做存储和检索，不会从做完的任务里沉淀经验，同类错误会反复出现。
- 方法：保留文本、图像、渲染页面的多视图记忆，并生成合成场景图来串联线索。用源数据生成任务：warm-up 阶段把知识整理成外部记忆里的经验，self-training 阶段把知识放进参数。同一个 VLM 把完成的任务蒸馏成「任务上下文＋结论＋支撑链接」的经验条目，检索时按任务召回源视图和相关经验。
- 结论/意义：Qwen3.5-9B 上，LoCoMo、Mem-Gallery、LooGLE v2 分别比最佳基线相对提升 36.9%、17.6%、15.2%，共超过 8 个基线。

### [VideoJSON: A Minimal Harness Beats Purpose-Built Memory for Ultra-Long Video Understanding](https://arxiv.org/abs/2611.28167)
- 热度：HF 👍8（入榜 1 天，新增 0）；代码 [weathon/videojson_release](https://github.com/weathon/videojson_release) 2 星
- 问题：数天到数周的超长视频，agent 依赖复杂记忆图和固定检索流程，搜索方式受限。
- 方法：索引时，VLM 把每分钟视频变成一条 JSON 记录，含密集 caption 以及事件、实体、地点、语音转写等结构化字段。查询时，coding agent 在沙箱里自己写 Python/Bash 去过滤、关联、读取这些记录，不碰原始视频。
- 结论/意义：用 DeepSeek V4.1 Flash，在 EgoLifeQA、Ego-R1-Bench、MM-Lifelong Week 上分别领先 MAGIC-Video 7.0、20.0、24.75 分。消融显示「agentic 代码搜索」和「结构化 JSON」都有贡献；加小时摘要、额外工具或视频访问，平均分变化不到 1.5，标题的论断有消融支持。摘要写的是「发表后开源」，仓库已存在。

### [MORSE: Optimizing Streaming Memory Design via Open-World Auto-Research](https://arxiv.org/abs/2611.30011)
- 热度：HF 👍4（入榜 2 天，新增 +2）；无代码仓库
- 问题：流式视频系统要在有限帧存储下、不知道未来问题时决定保留什么证据，而现有自动改进 harness 的方法只能靠编辑器已有知识修补。
- 方法：编辑器按原因给训练轨迹里的失败归类，再检索论文、模型卡和代码，寻找可借用的方法或预训练感知模型。引入新感知能力时，同时改写 harness 的存储与检索方式。先选提升准确率的改动，再在容忍范围内找更快的改动。
- 结论/意义：OvO-Bench 上，Qwen3-VL-8B harness 平均 0.30 秒响应，准确率 75.1%，比同一冻结骨干的次优 harness 高 3.1 个百分点。

### [Embodied-Harness: Towards Recursive Self-Improvement for Robotic Manipulation](https://arxiv.org/abs/2611.27689)
- 热度：HF 👍8（入榜 2 天，新增 +1）；无代码仓库
- 问题：VLM 机器人 agent 的记忆组织不足，失败归因不确定，执行经验复用有限。
- 方法：Actor 负责执行，Reflector 把执行证据转成可复用的操作指导。分层记忆分为短期执行上下文和长期经验知识。基于证据做失败诊断，再跨多次尝试迭代改进 harness，全程不更新模型参数。
- 结论/意义：RoboTwin 2.0、RoboSPA、RMBench 成功率分别为 82.4%、76.7%、94.4%；真机 3 个任务平均 96.7%。

### [Context-Grounded Skill Internalization for Vision-Language Agents](https://arxiv.org/abs/2611.30075)
- 热度：HF 👍4（入榜 1 天，新增 +1）；代码 [jinlinll/cgsi](https://github.com/jinlinll/cgsi) 2 星
- 问题：把 skill 从上下文里移除再微调，模型会去引用已不存在的 skill（作者称 context misalignment，CoMi）。在 ALFWorld、WebShop、ARC-AGI-1 上，12.2–46.0% 的测试轨迹出现这种引用。
- 方法：用句子检测器找出无依据的引用，微调前对这些句子做掩码或改写。
- 结论/意义：CoMi 降低 72.5–94.6%，任务成功率保持；与基于 RL 的 skill 内化基线性能相当，训练时间少得多。

### [RECAP: Training Long-horizon LLM Agents with Context Compaction](https://arxiv.org/abs/2611.31258)
- 热度：HF 👍1（入榜 1 天，新增 0）；代码 [eth-medical-ai-lab/recap](https://github.com/eth-medical-ai-lab/recap) 1 星
- 问题：摘要的好坏要在之后很多步才体现出来，如何用 RL 联合学习上下文压缩和 agent 策略。
- 方法：摘要应保留原历史所诱导的行为。用「行为失真」目标度量压缩前后后续行为的差异，梯度分解为两个信号：给摘要生成的失真奖励，和给后续动作的自蒸馏。
- 结论/意义：Qwen3.5-4B 上，BrowseComp-Plus 绝对提升 4.6%，SWE-bench Verified 提升 4.3%，均优于只用任务奖励的 RL 基线。点赞很低，但这是压缩的直接训练方法，故入选。

### [EvoViM: Recursively Self-Evolving Visual Agents for Exploration with Deferred Queries](https://arxiv.org/abs/2611.28574)
- 热度：HF 👍1（入榜 1 天，新增 0）；代码 [Lewis-Xinyu/EvoViM](https://github.com/Lewis-Xinyu/EvoViM) 18 星
- 问题：问题在探索之后才给出，agent 要在不知道哪些细节重要的情况下保留视觉证据。
- 方法：冻结的多模态模型把自己的交互经验变成一个「视觉程序」，这个程序同时管记忆和技能，保留图像并直接在像素上计算。记忆演化时，同一模型把失败溯源到丢失或误用证据的操作并修改；还会改写指导后续修改的笔记和分析工具，并跳过已失败的改动。
- 结论/意义：6 个任务上，相对最强基线 AutoMem，在留出 episode 上提升 31.3–47.6 分；仅凭初始环境说明一次写成的程序明显更差。

- [RoboEvo²: Recursive Robot Self-Improvement via Harness-Policy Co-Evolution](https://arxiv.org/abs/2611.34675)（👍9）：harness 与策略互相演化，经验沉淀为技能、路由策略和经验记忆。LIBERO-PRO 独立成功率从 11.0% 升到 84.1%。
- [EgoUseBench: Benchmarking Computer-Use Agents under Evolving First-Person Contexts](https://arxiv.org/abs/2611.34466)（👍18）：693 个任务，基于 74 小时第一视角录像；在线 Ego Use 的平均成功率比普通 Computer-Use 低 26.3%。
- [DFly2: Turbocharging Long-Context Speculative Decoding by Sharing the Target's Sparsity](https://arxiv.org/abs/2611.34776)：草稿模型共享目标模型的 KV 与稀疏选择，不再维护自己的 cache。在长上下文和 agentic 负载上，相对更强基线的接受 token 优势扩大到 10.0%–31.5%。
- [MINE: A Training-Free Defense against Indirect Prompt Injection](https://arxiv.org/abs/2611.34188)：用互信息和嵌入方差做免训练的、以查询为条件的重排序来防间接提示注入，也适用于 agent 工具调用注入（InjecAgent）。

## 研究趋势观察

- 模型自管上下文，推理引擎跟着协同设计：[NVIDIA 的论文](https://arxiv.org/abs/2611.34147)和 [Autoresearch 消融](https://arxiv.org/abs/2611.28244)指向同一个方向，保留可检索的历史记录优于摘要和合并。同日还出现 KV cache 编辑复用（省 15% 预填充）、多轮 agent 的 KV 保留（[PARK](https://arxiv.org/abs/2611.34584)）、cache 共享的投机解码（[DFly2](https://arxiv.org/abs/2611.34776)）等推理侧工作。
- Harness 与记忆自进化，改 harness 不改权重：Embodied-Harness、ReWeave、SEEK、RoboEvo²、MORSE、[EvoViM](https://github.com/Lewis-Xinyu/EvoViM) 的机制都是把失败证据转成对 harness 或记忆程序的改写。具身机器人方向尤其集中，多个机器人 harness 用 RoboDojo 评测。
- 热度与「上下文」错位：hot 里点赞最高的是 CUA 感知（[NightWatch](https://github.com/SuJQ0722/NightWatch)）、RL 训练（[RLVB](https://github.com/declare-lab/RLVB)）和机器人 coding agent（[ACAP](https://arxiv.org/abs/2611.31205)）。上下文类论文点赞偏低，新增也少；只有 NVIDIA 这篇在 new 里初步热度较高，2330 星是其 harness 仓库的星数。
- 评测可靠性受到质疑：[SWE-Gym](https://github.com/Arist12/SWE-Gym-Verified) 的奖励标签审计（74% 的「未解」任务可能是测试有误）和 [SkillsBench](https://arxiv.org/abs/2611.33943) 的源码审计，都在检查基准本身是否可信；[CUA-SEE](https://arxiv.org/abs/2611.30962) 走的是自演化评测的路线。
