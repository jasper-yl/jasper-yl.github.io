## 🔥 热度榜：Agent Context 精选

### [MIRIX-2.0: Multi-Agent Memory System](https://arxiv.org/abs/2611.12068)
- 热度：HF 👍26（入榜 6 天，新增 +26）；代码 [Mirix-AI/MIRIX](https://github.com/Mirix-AI/MIRIX) ⭐3472；数据里没有 X 提及数。已在 11-10、11-15 日报出现，本期第三次，持续在榜。
- 问题：长期记忆里，参数化记忆需要训练，整合会永久丢失细节，全部保留又让存储越来越难检索。
- 方法：六个类型化记忆 agent，保留完整记录作为系统记录。用溯源超图索引情景和语义记录，n 元 frame 引用其所在行。检索有显式预算，所查证据不随历史增长。AutoDream 在写入路径之外合并重复锚点（不改写任何记录），并把任务会话提炼成 skill。无需微调，开闭源模型都能跑。
- 结论/意义：五个 QA 基准里四个最准，LoCoMo 91.4%，LongMemEval-S 72.6%（领先最强基线 14.3 点）。关闭 AutoDream 时，五个计时基准上都比 HyperMem 快。程序性记忆上，MetaClaw-Bench 49.2%，MetaClaw skill 库为 44.0%。

### [Can LLM Agents Organize Their Own Memory?（SoMem）](https://arxiv.org/abs/2611.11929)
- 热度：HF 👍0（来源 arxiv，入榜 6 天）；代码 [Qi202/SoMem](https://github.com/Qi202/SoMem)，数据里没有星数。11-10 日报已提过，与 MIRIX-2.0 同日出现，路线不同。
- 问题：预定义的记录和固定的组织规则难以适应变化的任务。
- 方法：记忆存成互相链接的普通文档。agent 自己决定摘要什么、怎么归类、何时修订主题，每条摘要都链回原始交互作为证据。运行时校验更新，并自动派生时间、关系、近期记忆视图。查询时 agent 自己选择搜什么、读什么，沿链接追到原始证据。
- 结论/意义：LoCoMo、BEAM-100K、LongMemEval-S 分别领先最强基线 2.66、3.10、2.00 个百分点，构建出的记忆可跨模型复用。

### [Compaction, decay and reinforcement in a two-tier conversational memory](https://arxiv.org/abs/2611.09807)
- 热度：HF 👍0（入榜 7 天）；无代码数据。
- 问题：对话 agent 该保存转录原文并检索（RAG），还是压缩成原子事实再检索？
- 方法：在 LoCoMo 上，两种方案回答全部 1,985 题，用同一批存储、同一个生成器和评审，并对 512 道结果不一致的题做 McNemar 精确检验。
- 结论/意义：在可比工作报告的四类上，压缩 71.4% 对 64.6%（+6.8，p=5.5e-08），prompt token 少 34%。算上对抗类的全部五类，领先缩到 2.0 且不再显著，因为 RAG 在对抗类领先 14.6。答案越需要原话，压缩越吃亏：参考答案 1–2 个词时领先 9.6，超过 8 个词时落后 3.1。压缩保留断言内容，丢掉措辞。论文还报告了四个负结果。

### [Review the Episodes, Refine the Lessons: Simple Memory Evolution for Embodied Agents（SimplEvo）](https://arxiv.org/abs/2611.11509)
- 热度：HF 👍0（入榜 6 天）。
- 问题：给前沿 MLLM 套上后训练策略、递归自改进等 harness，是否真的超过 MLLM 自身的能力？
- 方法：不更新权重，不用特权信息。MLLM 从一次演示写出一份无坐标的任务记忆，在训练 episode 上建立有界工作记忆，每个 episode 后用「流程、完成、恢复」类教训精炼。测试时两份记忆固定。
- 结论/意义：EBench 上 GPT-6-Astra 的成功率从 46.7% 升到 81.7%，登上 RoboDojo 榜首（SR 69.63%）。只用文本记忆，成功率与同时存过往视觉帧的记忆相近，token 用量更少。工作记忆可原样被更弱的 MLLM 复用。

### [MemoryDojo: Benchmarking Poisoning Through LLM Agent Memory](https://arxiv.org/abs/2611.09721)
- 热度：HF 👍0（入榜 7 天）。
- 问题：一个会话里遇到的恶意指令可能被存进记忆，在后续会话被检索并执行。
- 方法：基准含 155 条多会话长程轨迹，覆盖 4 个领域，支持 5 种记忆系统，追踪被投毒信息在记忆中的生命周期及对后续行为的影响。另提出记忆感知的投毒优化。
- 结论/意义：所有被测记忆系统都易受投毒，下游影响差异很大。

### [Verify Before You Fetch: Reliable KV Cache Compression for LLM Inference（VerKV）](https://arxiv.org/abs/2611.11319)
- 热度：HF 👍0（入榜 6 天）。
- 问题：长上下文和长生命周期 agent 的 KV cache 超出 GPU HBM，需卸载到 CPU，传输拖慢推理；查询无关的压缩又很难保证任意查询的注意力准确。
- 方法：GPU 上保留一小组查询无关的关键 token（PoissonComp 采样），外加全 cache 的 token 级 sketch，完整 cache 留在 CPU。推理时 KVFetch 估计注意力的相对误差，满足 (ε, δ) 容限就不访问主机内存，否则做查询感知检索补取 token。
- 结论/意义：在 Qwen3-4B、Qwen3.5-9B、Ministral-3-8B 上，32K 上下文保持 90–100% 稠密质量（RULER 和 LOFT 平均），GPU 内存占用降 8–32 倍，每个生成 token 的 CPU→GPU 取数为 cache 的 2–23%。

### [From LoRA to Language: Recovering Skill Documents from Adapters](https://arxiv.org/abs/2611.09454)
- 热度：HF 👍0（入榜 7 天）。
- 问题：为省上下文，skill 文档被编译进 LoRA，行为留下了，文本却丢了，难读、难改、难审计、难迁移。
- 方法：只读权重几乎恢复不了，运行适配后的模型更有效。Executing Writer 在适配模型之上训练一个小写手来恢复文档；对只靠行为训练的 adapter，则用一个 agent 对比基座与适配模型的差异来写 skill。
- 结论/意义：留出 skill 的关键指令恢复 39–44%（换用另一个 skill 的 adapter 只有 1.3–1.5%）。在 41 个外部 skill 的 adapter 上，恢复的文档还原了原始任务增益的 85–91%。行为型 adapter 上，ALFWorld 恢复 LoRA 增益的 58–71%，Llama-3.1-8B 从 5% 升到 55%。

## 🔥 热度榜：Agent 其他方向

- [ScrapeBench: Evaluating Legal Compliance of AI Agents in Website Scraping](https://arxiv.org/abs/2611.11306) · HF 👍4 · 入榜 4 天：在 1,626 个明确禁止抓取的网站上，多数 agent 合规率不足 5%；在 269 个不禁止的网站上，Claude Opus 4.6 的过度拒绝率为 98.5%；人类基线（n=180）合规率与 agent 相当，过度拒绝更多。
- [Learning to Act with World Models by Valuing What Comes Next（WM-PPO）](https://arxiv.org/abs/2611.12200) · HF 👍3 · 入榜 5 天：用世界模型预测每个候选动作的下一观测，再由 critic 给后继状态估值，产生辅助优势和辅助目标。ALFWorld 成功率从 63.5% 到 87.5%，ScienceWorld 从 39.3% 到 52.9%。
- [From Procedures to Permissions: Learning Precise Subagent Authorization from Agent Skills](https://arxiv.org/abs/2611.08905) · HF 👍0 · 入榜 7 天：用 Agent Skills 里的流程知识合成任务，监督 subagent 该拿哪些工具和工作区权限。ClawArena-Team 上工具权限精度 +13.4 点，工作区权限精度 +24.1 点，任务成功率 +11.6 点（Qwen3.5-35B-A3B）。
- [ErosionBench: Probing Alignment Decay in Enterprise Multi-Agent Systems](https://arxiv.org/abs/2611.11266) · HF 👍0 · 入榜 6 天：1,728 个场景，评估跨会话的共享状态投毒如何让多 Agent 系统逐步做出不安全的工具调用，按实际工具调用判分。边界防御靠过度拒绝 54–92% 的正常工作来压低攻击成功率；提出的 Meta-Auditor 在 906 个留出场景上召回 98.5%，误报 2.9%。
- [PRISM: Causal Counterfactual Minimization of Agent Tool Privileges](https://arxiv.org/abs/2611.11539) · HF 👍0 · 入榜 6 天：针对 MCP 下 agent 工具权限过度授权，用沙箱干预学习工具必要性，用信息瓶颈归纳角色。每个角色的授权工具数压缩 78.3%，任务成功率 78.2%，爆炸半径降到 15.9%。
- [EmoHarness: Boosting Multimodal Emotion Understanding with Meta-Harness Evolving](https://arxiv.org/abs/2611.11994) · HF 👍2 · 入榜 5 天：让更强的 LLM（Builder）离线读取冻结小模型的错误和执行轨迹来编辑 harness。MME-Emotion 上 Recognition 提升 7.6–13.4 点，但增益主要来自转录和韵律证据（+5.38 到 +10.71），进化出的编辑最多 +0.95，经 Holm 校正后不显著，可作为「harness 自进化」的冷静对照。

## 🆕 New：昨晚新公布

- [Envisioning Agentic Robotics: A New Era of Robotic Systems](https://arxiv.org/abs/2611.18359)：提出「具身 System 2」（基础模型加具身 harness）作为 agentic robotics 的决策核心，给出评估框架和面向持续自主的路线图（初步热度 👍107，今日最高）。
- [Gamer](https://arxiv.org/abs/2611.18397)：面向长程实时游戏的通用 VLA agent，训练时用多轮 RL 应对有限上下文窗口，推理时用云边引擎支持无界上下文（👍86）；代码 [RainBowLuoCS/Gamer](https://github.com/RainBowLuoCS/Gamer) ⭐124。
- [VibePrevisBench](https://arxiv.org/abs/2611.15789)：评测编码 agent 在 Blender 里重建 4D 场景的基准，242 个任务，11 个前沿 agent；发现 agent 会检查自己的渲染，却不会据此纠错（👍82）。
- [G-CAST](https://arxiv.org/abs/2611.17814)：电商 agent 的受治理持续自训练，把线上证据转成训练数据，在需求漂移和 harness 演进下保住已有能力；已部署在阿里 1688 的采购 agent（👍17）。
- [Aligning AI Teams](https://arxiv.org/abs/2611.17820)：研究单 agent 的对齐为何不能迁移到多 agent 团队；责任分散是主因，指定安全负责人 agent 或发布安全规范文档能恢复对齐；发布 magelab 框架（👍12）。
- [WebArena-Pro](https://arxiv.org/abs/2611.17955)：300 个任务、20 个自托管 web 应用的可复现多模态 web agent 基准，音频和视频作为核心观测；最佳成绩 62.3%（👍10）。
- [Continual-ARC](https://arxiv.org/abs/2611.14505)：用 ARC-AGI 构造终身任务流，把记忆型和权重型学习放在同一尺度比较；harness 持久化一般不提升记忆，在未见任务上也无增益，权重学习则增益明显（👍9）；代码 [unifyai/continual-arc](https://github.com/unifyai/continual-arc) ⭐37。
- [CarryOn: Learning What to Keep in Context for Long-Horizon LLM Agents](https://arxiv.org/abs/2611.17808)：轻量上下文管理器，把紧凑的执行状态和可溯源的细粒度证据配对，用学习式选择器加自适应保留，不需要额外的 LLM 调用；AppWorld、OfficeBench、Tau2 Telecom 上宏平均成功率 75.7%，比最强基线高 6.7 点。与今日 Agent Context 主题最贴合的 new 论文。
- [Forget the Lineage（LinEra）](https://arxiv.org/abs/2611.18133)：给 agent 记忆做前向安全的密码学擦除，每条记忆用其父记忆派生的密钥加密，遗忘只需一次 puncture；与 mem0 集成，在 LoCoMo 上攻击者持有全部文件和当前密钥时，LinEra 下恢复 0 个被遗忘的秘密（逻辑删除下是 70/71）。代价是遗忘半径：遗忘 1% 的轮次，会话级摘要下擦除 73.0% 的派生记忆，四轮窗口下仅 3.8%。
- [Interpreting Coding Agents Through Their Behavioral Trajectories](https://arxiv.org/abs/2611.17440)：分析 125 种配置、143,209 条编码 agent 轨迹，用规则解析器把轨迹映射成搜索、编辑、测试等动作；解出率相近的 agent 行为差异很大，scaffold 和推理强度会系统性改变行为（👍4）。
- [GH-AWTrace](https://arxiv.org/abs/2611.06866)：GitHub Agentic Workflow 执行日志数据集，含 25,014 个工作流、5,051 个仓库、4,112,526 条运行记录（👍10）。

## 研究趋势观察

- 记忆方向在热度榜上最集中。[MIRIX-2.0](https://arxiv.org/abs/2611.12068)（类型化多 agent、超图、以完整记录为准）、[SoMem](https://arxiv.org/abs/2611.11929)（普通链接文档）、[2611.09807](https://arxiv.org/abs/2611.09807)（压缩对比 RAG）和 [SimplEvo](https://arxiv.org/abs/2611.11509)（文本经验记忆）都保留可溯源的原文或证据。new 里的 [CarryOn](https://arxiv.org/abs/2611.17808) 同样采用「紧凑状态加源链接证据」。
- 记忆的安全面开始被单独研究：[MemoryDojo](https://arxiv.org/abs/2611.09721) 测投毒，[LinEra](https://arxiv.org/abs/2611.18133) 做擦除，[ErosionBench](https://arxiv.org/abs/2611.11266) 测跨会话共享状态的侵蚀，[PRISM](https://arxiv.org/abs/2611.11539) 和[子 agent 授权论文](https://arxiv.org/abs/2611.08905)管工具权限。
- KV cache 方面，除 [VerKV](https://arxiv.org/abs/2611.11319) 外，[Nebula](https://arxiv.org/abs/2611.09474)（分布式位置无关缓存，median TTFT 平均降 61.4%，找回前缀缓存漏掉 token 的 76.1%）也在榜，两篇的动机都明确提到 agent 和 RAG 的长 prompt。
- 工程侧：本期输入没有 GitHub 项目数据，只有论文仓库星数。[Mirix-AI/MIRIX](https://github.com/Mirix-AI/MIRIX) ⭐3472 远高于其他，[RainBowLuoCS/Gamer](https://github.com/RainBowLuoCS/Gamer) ⭐124，[InfrathonX/Infrathon](https://github.com/InfrathonX/Infrathon) ⭐39，[unifyai/continual-arc](https://github.com/unifyai/continual-arc) ⭐37，其余多在 10 以下。不写与工程项目的对应关系。
