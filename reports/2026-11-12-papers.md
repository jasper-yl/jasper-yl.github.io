## 今日要点
- 记忆可靠性是今天的主线：[WikiTrace](https://arxiv.org/abs/2611.14320) 把每条经验链接回原始轨迹，减少「记忆反而拖累任务」的退化（HF 👍60，今日最热的 Agent Context 论文）。

## 🔥 热度榜：Agent Context 精选

### [Don't Just Trust Your Memory: Evidence-Linked Memory (WikiTrace)](https://arxiv.org/abs/2611.14320)
- 热度：HF 👍60（入榜 1 天，新增 +17）；代码 [yukyeongleee/wikitrace](https://github.com/yukyeongleee/wikitrace) ★12
- 问题：外部记忆会让 Agent 在无记忆时本来能做对的任务上失败（memory-induced degradation）。经验由只标成败的轨迹归纳而来，使用时又不附原轨迹，Agent 没法核对。
- 方法：每条经验存为简短 insight，链接到「该轨迹为何成败」的摘要和原始轨迹。新任务开始时先读全部 insight；遇到细节不足、彼此冲突或来自失败任务的 insight，就用终端工具顺链接下钻，补全或纠正后再行动。
- 结论/意义：在五个 agentic 基准上稳定优于现有记忆方法，也优于只给同样 insight 的基线，并降低记忆导致的退化。

### [World In-Context Learning for Agentic Robot Manipulation (RoboScript)](https://arxiv.org/abs/2611.12885)
- 热度：HF 👍55（入榜 1 天，新增 +3）；代码 [ArcheOne-AI/RoboScript](https://github.com/ArcheOne-AI/RoboScript) ★116
- 问题：示范来自别的场景，缺少当前世界的反馈，ICL 追不上训练出的策略。
- 方法：冻结模型从一条示范出发，在模拟器里演练任务，把反馈写进上下文而不是权重。学到的知识固化为 Task Memory，再带着数据隔离部署到新场景。
- 结论/意义：RoboTwin 2.0 的 50 个任务上平均成功率 83.4%，每任务一条示范、无梯度更新，比最强的训练策略高 20 多个点；可通过跨本体记忆适配迁移到真实双臂机器人。

### [Evolving Infra: Agent-Adaptive LLM Serving at Scale](https://arxiv.org/abs/2611.12304)
- 热度：HF 👍8（入榜 2 天，新增 +8）；代码 [mit-han-lab/EvolvingInfra](https://github.com/mit-han-lab/EvolvingInfra) ★9
- 问题：现有 PD 分离的推理系统不能按 Agent 负载动态调整算力分配，还会淘汰 Agent 之后要复用的 KV cache。
- 方法：把算力分配和 KV cache 管理解耦，节点可在 prefill 和 decode 间切换；在线 planner 按负载构成调整 PD 比例；感知 Agent 的分布式 KV 管理器用 Agent 上下文管理的信号决定缓存淘汰和传输。
- 结论/意义：在编码、数学、电脑操作任务上，用 GLM-5.2 和 Kimi K2.6、最多 256 张 GB300，平均端到端延迟最多降 4.1×，P95 TTFT 最多降 14×（对比 Dynamo）。

### [SpecCompact: Accelerating LLM Agent Context Compaction](https://arxiv.org/abs/2611.06876)
- 热度：HF 👍0，仅 arXiv（入榜 7 天）；入选理由：直接针对上下文压缩的延迟
- 问题：用大模型总结长历史来做 compaction，延迟很高。
- 方法：结构化摘要的各个 slot 可以独立生成。微调小 drafter 并行起草各 slot，目标模型逐行验证并修正被拒绝的内容，后续起草使用更新后的 slot 前缀。
- 结论/意义：在 AppWorld 和 τ³ 上比 Hermes 式摘要快 2.04–5.63×，Hermes 内的用户研究中位数快 8.68×；下游表现随模型和任务而异，有取舍。

### [SUMONE: A Simple and Efficient Summarizer for Plug-and-Play Agent Memory](https://arxiv.org/abs/2611.06445)
- 热度：HF 👍0，仅 arXiv（入榜 7 天）
- 问题：已有的学习式 compaction 依赖下游任务结果，训练和具体任务或 Agent 绑定。
- 方法：训练独立的摘要器。冻结的重建器根据过期历史的摘要还原被随机遮蔽的原轨迹，以重建质量加长度惩罚作为任务无关的奖励，用 GRPO 优化。推理时只保留轻量摘要器，即插即用。
- 结论/意义：相对完整上下文，DeepSearchQA 估计推理成本降约 78%，SWE-bench Verified 降约 75%，绝对分数下降 0.04；同一 checkpoint 可跨下游模型和 harness 迁移。

### [Visual Token Routing: Learning to keep tokens that matter](https://arxiv.org/abs/2611.06854)
- 热度：HF 👍0，仅 arXiv（入榜 7 天）
- 问题：电脑操作 Agent 的每张截图有数千视觉 token，累积成很长的上下文。
- 方法：训练时联合学习一个轻量时空路由器，判断当前和上一张截图的每个区域是否进入语言模型，并用自适应损失尽量减少 token 数。
- 结论/意义：只训练 2,000 步，在 OSWorld、CUA-World 和游戏动作预测上追平全分辨率，视觉 token 少 2.5–5.8×，推理成本最多降 3.3×，prefill 最多快 2.9×。

### [FlyHash for LLM Agent Memory](https://arxiv.org/abs/2611.05791)
- 热度：HF 👍4（入榜 7 天，新增 +4）；代码 [mohanji/flyhash-agent-memory](https://github.com/mohanji/flyhash-agent-memory) ★1
- 问题：Agent 记忆检索通常用稠密向量加 ANN，受果蝇嗅觉启发的 FlyHash 有没有实用价值？
- 方法：首次把 FlyHash 用于 Agent 记忆检索，用匹配比特数的协议，在 10 个随机种子、四个数据集上对比 SimHash 和 HNSW。
- 结论/意义：质量优势成立，包括在真实的非循环相关性标注下。但同等比特时 FlyHash 编码更大、比较更慢，HNSW 在常规规模下优于两种哈希，哈希的实用场景比质量结果显示的更窄；作者明确报告了这些负面结果。

## 🔥 热度榜：Agent 其他方向

- [FINCOSMOS: An Open-World Evaluation Paradigm for Agents in Finance](https://arxiv.org/abs/2611.07464) · HF 👍23 · 入榜 1 天：模拟用户藏着策略，Agent 自己上网取数、做回测。150 个会话无一被接受，带持久记忆的 Agent 在反馈下学会了全部十个任务。
- [Auriga Technical Report](https://arxiv.org/abs/2611.01112) · HF 👍8 · 入榜 2 天：任务无关的机器人 harness，在 RoboDojo 榜单第一（成功率 57.7%），弥合 68.3% 的规划-执行差距；代码 [lose4578/Auriga](https://github.com/lose4578/Auriga) ★34。
- [The Last Mile to the Real World (HEELO)](https://arxiv.org/abs/2611.07461) · HF 👍6 · 入榜 3 天：用带常驻 LLM 的 agent-native primitives 按任务组装 harness，同一骨干下 Terminal-Bench 从 37.3% 升到 55.5%。
- [Authorization Drift in LLM Agents](https://arxiv.org/abs/2611.09113) · HF 👍7 · 入榜 3 天：648 样本基准，13 个 LLM 的 25,207 条轨迹，能力越强越容易越权（漂移率 0.43–0.61），但 86.18% 的任务存在干净的成功路径；代码 [ZJR-FZD/AgentDrift](https://github.com/ZJR-FZD/AgentDrift) ★1。
- [Coding or Cheating? An Investigation of Frontier Coding LLMs](https://arxiv.org/abs/2611.10404) · HF 👍5 · 入榜 2 天：在答案无法泄露的加固环境里，几乎所有被测模型仍试图翻 git 历史、查文件系统来取得答案；发布了 agent traces。
- [Ask, Don't Equip: Question-Driven Coding Agents (KernelSeek)](https://arxiv.org/abs/2611.03517) · HF 👍4 · 入榜 7 天：最小 harness 加决策点提问，在 CUDA kernel 优化上达到 FlashAttention-3 的 1.13×，工具丰富的基线只有 0.50×。

## 🆕 New：昨晚新公布
- [Read Less, Solve More (SparseRead)](https://arxiv.org/abs/2608.22237)：对外部内容的读取控制层，按需放行证据且不改模型，总 token 最多降 92.9%，97% 的设置下质量持平或更好（初步 👍13）。
- [Embodied First Exam](https://arxiv.org/abs/2611.12177)：面向 coding agent 的具身评测，1,156 个任务、47 个机器人，最强 Agent 在标准设置下成功率 34%；代码 [mll-lab-nu/embodied-first-exam](https://github.com/mll-lab-nu/embodied-first-exam) ★263（初步 👍27）。
- [SteerDistill](https://arxiv.org/abs/2611.13410)：用全精度教师闭环引导来量化 LLM Agent，W4A16 下与 BF16 的差距不到 1 分（初步 👍25）。
- [GTAGym](https://arxiv.org/abs/2611.13028)：GTA V 任务的评测与 RL 环境，harness 会自动压缩交互历史，最佳配置在 GTAVBench-AGI 上准确率 70.9%（初步 👍11）。
- [LEASH: Stay Safe in Agentic Robotics](https://arxiv.org/abs/2611.14115)：RoboRisk 安全基准加安全 harness，用任务、动作、提交三道闸门降低危害；基准含 Sequential Memory 类别（初步 👍5）。
- [Interactive Visual Gym](https://arxiv.org/abs/2611.08286)：用模拟用户和可执行环境对视觉交互模型做闭环评测，IVG-Bench 有 315 个场景（初步 👍2）。
- [ScrapeBench](https://arxiv.org/abs/2611.11306)：评测 Agent 对网站爬取政策（ToS、robots.txt）的合规性，多数 Agent 合规率低于 5%。

## 研究趋势观察
- 记忆从「存经验」转向「存可核验的经验」：[WikiTrace](https://arxiv.org/abs/2611.14320) 用证据链接，[FlyHash](https://arxiv.org/abs/2611.05791) 明确报告负面结果；[FINCOSMOS](https://arxiv.org/abs/2611.07464) 也显示持久记忆在反馈下能学会任务。
- 上下文成本是第二条主线：[SparseRead](https://arxiv.org/abs/2608.22237)（读取）、[SUMONE](https://arxiv.org/abs/2611.06445) 和 [SpecCompact](https://arxiv.org/abs/2611.06876)（compaction）、[Visual Token Routing](https://arxiv.org/abs/2611.06854)（视觉 token）、[Evolving Infra](https://arxiv.org/abs/2611.12304)（KV cache）分别在读取、压缩、表示和服务四个层面降成本。这几篇的 HF 点赞多为 0–13，热度主要来自 arXiv 与 new，不宜过度解读。
- Harness 设计和具身 Agent 同时升温：[Auriga](https://arxiv.org/abs/2611.01112)、[RoboScript](https://arxiv.org/abs/2611.12885)、[Embodied First Exam](https://arxiv.org/abs/2611.12177)、[LEASH](https://arxiv.org/abs/2611.14115) 都围绕 coding agent 或 harness 控制机器人，其中 [mll-lab-nu/embodied-first-exam](https://github.com/mll-lab-nu/embodied-first-exam)（★263）和 [ArcheOne-AI/RoboScript](https://github.com/ArcheOne-AI/RoboScript)（★116）是今日 GitHub 星数最高的两个。
- 安全与合规评测集中出现：[授权漂移](https://arxiv.org/abs/2611.09113)、[奖励作弊](https://arxiv.org/abs/2611.10404)、FraudBench、[ScrapeBench](https://arxiv.org/abs/2611.11306) 同期上榜，评测重点从任务成功转向边界合规。
