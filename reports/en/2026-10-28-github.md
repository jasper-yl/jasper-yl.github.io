### Theme 3: codebase indexing / knowledge graphs / search

Goal: let agents query structured knowledge instead of stuffing full text into context. Deterministic parsing plus a graph is becoming the standard approach.

- [Graphify-Labs/graphify](https://github.com/Graphify-Labs/graphify) · ⭐137,492 · +781/day: turns codebases, docs, SQL schemas and PDFs into a queryable knowledge graph. It uses local deterministic AST parsing (tree-sitter), explains every edge, and needs no vector store.
- [xerj-org/xerj](https://github.com/xerj-org/xerj) · ⭐17,282 · +266/day: a single Rust binary that indexes code, docs, logs and PDFs. It offers BM25, vector and hybrid search, is compatible with the Elasticsearch API, and doubles as an MCP server and agent memory. +5,091 this week.
- [NVIDIA/auto-ontology](https://github.com/NVIDIA/auto-ontology) · ⭐483 · +230/day: builds a semantic graph reasoning layer over data for deterministic query generation and better context retrieval. (more in section 3)

## 4. Observations

- Skills have become the main way to distribute agent capabilities, and they are splitting into roles: taste (hallmark, impeccable, taste-skill), engineering method (Google's elephant-goldfish-model, superpowers, tstack) and security (cloudflare/security-audit-skill, NVIDIA/SkillSpector). Big companies (Google, Cloudflare, NVIDIA, JetBrains) appear on the list noticeably more often.
- Reverse engineering (the `rea` tag) has become a small ecosystem. [morluto/rea](https://github.com/morluto/rea) is at ⭐400,898 and +5,248/day (24 days in a row, but falling: 7-day average 6,951, peak 54,105). The awesome lists around it keep climbing (Awesome-REA 11 days in a row, awesome-reverse-engineered, awesome-reverse-engineer-anything), so growth has spread from the main project to surrounding directories. (the 10-27 report made the same call)
- Two lines run in parallel: desktop multi-agent workspaces and dsh plugins. openbot, Orkas, cindy, thinkrail and orca all manage multiple agents on the desktop. The dsh host holds steady at 700–1,500/day, with model-access plugins and MCP handoff tools like dsh-baton around it. Several projects went from single-digit daily gains to over a thousand within two days (DeepTutor, postiz-app, openbot, Orkas). The data doesn't show where their traffic came from, unverified.
- One non-agent hot spot: the TV ad-removal project [Gathin23/cleanyourtv](https://github.com/Gathin23/cleanyourtv) (⭐43,263, +2,269/day, 11 days in a row, peak 6,816 on 10-20). It spreads through "hand a prompt to Claude Code". It is an application use case, so it is not on the list. (see the 10-27 report, same treatment)
