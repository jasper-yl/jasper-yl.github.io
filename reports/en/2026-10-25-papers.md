## 1. 🔥 Trending: Agent Context picks

### [Self-Evolving Agent Harness](https://arxiv.org/abs/2610.18813)
- Popularity: HF 👍99 (on the list for 2 days, +0 new); repo [zgcagi/Harness-RSI](https://github.com/zgcagi/Harness-RSI), 387★
- Problem: With model weights unchanged, how can an agent's scaffolding (prompts, memory, workflows, executable components) keep evolving reliably through feedback?
- Method: Formalizes the "update object" separately from the "proposal/admission mechanism", distinguishing changes to interpretive state from revisions to tools, code, repo-level control logic, and plugin composition. It uses evolutionary optimization to describe the search and continual PAC learning to analyze reliability, giving generalization bounds, retention bounds, and admission rules based on fresh, independent validation data.
- Conclusion/significance: Long-term deployment needs continuous validation, plus independent safeguards for learning, runtime permissions, and high-consequence actions. The paper is a 66-page survey plus theory.

### [Mosaic: Multi-Session Agentic Reinforcement Learning](https://arxiv.org/abs/2610.22174)
- Popularity: HF 👍63 (on the list for 2 days, +0 new); repo [LARK-AI-Lab/Mosaic](https://github.com/LARK-AI-Lab/Mosaic), 37★
- Problem: Context compaction and sub-agent forking make one trajectory span multiple sessions, but existing agentic RL assumes single-session context, so training and inference are mismatched.
- Method: Proposes a multi-session agentic RL setting and a critic-free hierarchical optimization method. At the trajectory level, session-usage signals are folded into advantage estimation. At the session level, each session's advantage is adjusted by its estimated marginal contribution, instead of broadcasting the trajectory-level advantage to all sessions.
- Conclusion/significance: On BrowseComp (Qwen3.5-4B), it beats the broadcast baseline in both the context compaction and sub-agent forking scenarios, while using fewer sessions on average.

### [Focused Omni-Modal GUI Agents](https://arxiv.org/abs/2610.26203)
- Popularity: HF 👍96 (on the list for 3 days, +65 new); repo [fyzhang1/FocusGUI](https://github.com/fyzhang1/FocusGUI), 31★
- Problem: Streaming omni-modal observations (screenshots, audio, video, history, device state) are exposed uniformly at every step. Relevance is transient and sparse, so irrelevant information accumulates into "sequential distraction" and causes trajectory drift.
- Method: Proposes FocusGUI, a lightweight adapter that dynamically ranks each modality channel by the current step's decision reference, compresses the most relevant evidence into compact latents, and injects them into the frozen decoder's embeddings. It is trained only with action supervision, needs no modality-relevance labels, and does not fine-tune the backbone.
- Conclusion/significance: Across four omni-modal backbones, Type Match improves by +33.2 on average, and Exact Match reaches 3.0 times that of the frozen backbone.

### [Socratic Skill Learning: Interleaving Teaching and Practice for Transferable Agent Skills](https://arxiv.org/abs/2610.17860)
- Popularity: HF 👍47 (on the list for 3 days, +17 new); repo [NJU-LINK/Socratic-Skill-Learning](https://github.com/NJU-LINK/Socratic-Skill-Learning), 2★
- Problem: A successful task attempt does not necessarily test the conditions under which a procedure applies, which makes transferable Skills hard to learn.
- Method: In SSL, an expert Educator guides while the Student operates the environment alone and writes Skills, and can ask questions, run tests, and revise suggestions. It also builds SkillTransferBench (35 task families, 408 executable cases) to test Skill reuse. The Issue-Guided version tracks unresolved issues across Skill revisions and uses them to select and focus reviews.
- Conclusion/significance: Fixed-Window SSL reaches a utility of 0.801, versus 0.723 with no Skill. The Issue-Guided version reaches a utility of 0.805 and cuts Educator tokens by 61.7%.

### [Memory-Centric Continual Learning for AI Agents](https://arxiv.org/abs/2610.29357)
- Popularity: HF 👍42 (on the list for 3 days, +23 new); no repo yet
- Problem: External memory is mostly a passive retrieval cache, evaluated only on whether facts can be recalled, which does not show whether memory leads to continual learning.
- Method: Proposes MCCL, with a three-axis taxonomy (where state is stored, its form, and management policy) and a dual-loop lifecycle: the inner loop updates memory state, and the outer loop improves the management policy from task feedback. It also offers an evaluation protocol (retention under interference, adaptation to change, task transfer) and a memory scaling framework over experience, storage, and compute.
- Conclusion/significance: Argues that memory should be measured by "whether it improves future actions". This is a framework paper, and the abstract gives no experimental numbers.

### [MemPilot: Orchestrating On-Demand Multimodal Memory Curation for LLM Agents](https://arxiv.org/abs/2610.06830)
- Popularity: HF 👍39 (on the list for 3 days, +3 new); repo [ViktorAxelsen/MemPilot](https://github.com/ViktorAxelsen/MemPilot), 7★
- Problem: Most memory systems are built up front, independent of the query, so preprocessing is wasteful and details that only matter later may be lost.
- Method: Uses RL to train a multi-step policy that chooses between "retrieving from query-agnostic memory" and "handing the raw multimodal history to heterogeneous LLMs/VLMs for query-tailored curation", while controlling evidence volume, curation instructions, model choice, and visual access. Training uses objective-level advantage decoupling and prefix-based marginal utility estimation for credit assignment.
- Conclusion/significance: On five multimodal memory benchmarks, the performance-cost-latency frontier under different preferences is wider than that of existing trade-off-aware baselines.

### [Retrieval Augmented Generation Compositionality](https://arxiv.org/abs/2610.29722)
- Popularity: HF 👍54 (on the list for 3 days, +29 new); repo [dolev31/lasagna](https://github.com/dolev31/lasagna), 18★
- Problem: Techniques in RAG pipelines such as chunking, reranking, and context compression are usually evaluated alone, and it is unclear whether their gains persist when combined.
- Method: Proposes LASAGNA, an open-source evaluation framework, testing 450 configurations on 8 benchmarks with corpora of 5K–200K documents, with three hypotheses declared in advance.
- Conclusion/significance: Three retrieval techniques are predicted to give +47% combined, but only +17% is measured when combined. Retrieval quality and answer faithfulness may conflict, and the best combination also changes with corpus size.

### [DeltaStreamer: Towards Human-Like Agentic Streaming Video Understanding](https://arxiv.org/abs/2610.19849)
- Popularity: HF 👍38 (on the list for 2 days, +0 new); repo [BBBBchan/DeltaStreamer](https://github.com/BBBBchan/DeltaStreamer), 87★
- Problem: Streaming video requires keeping evidence without knowing future questions. Compressing history blurs event turning points and cannot recover missing visual details.
- Method: Before a query arrives, it keeps observing and explicitly writes visual changes into a structured change-aware memory. After a query arrives, a planner determines the evidence needed and guides memory retrieval and targeted replay of past frames.
- Conclusion/significance: On OVO-Bench and StreamingBench, it scores 66.07% and 59.53% overall, outperforming the compared streaming methods.

## 5. Research trend observations
- **Harness and scaffold self-evolution is the most concentrated theme**: "Self-Evolving Agent Harness", Self-HPO, Terminal-RSI, and the Physical AI RSI survey (👍58) all revolve around "improving the improvement process itself". The Harness-RSI repo already has 387★ on the engineering side, showing community attention goes beyond the papers.
- **Context management shifts from "how to compress" to "how to train and evaluate"**: Mosaic brings compaction/forking into RL, MCCL proposes evaluating memory by behavioral gains, and FocusGUI filters relevant modalities at each step. All three treat context as something to optimize, not a static input.
- **Environment and evaluation infrastructure takes up most of the trending list**: MAI-Gym, WildAWM, CoworkEnv, OpenMobile-2, FDE-Gym, and others all address the scarcity and verifiability of training environments. The repos with the most GitHub stars are OpenGCUA (441★), GameScaling (380★), and Intern-Decision (775★). The latter two lean toward embedded/game decision-making and have limited direct relevance to Agent Context.
- **Signals to treat with caution**: The RAG compositionality paper points out that isolated gains do not stack, which is a reminder for single-point conclusions in context-engineering papers. Among this issue's memory and Skill papers, MCCL is a framework with no experimental numbers, and Socratic Skill Learning has only 2★, so engineering validation remains to be seen.
