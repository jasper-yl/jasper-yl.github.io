### [MMMem: Self-Improving Agents with Task-Aware Multimodal Experience Consolidation](https://arxiv.org/abs/2611.30287)
- Heat: HF 👍10 (2 days on the list, +9); code [ChenYX24/MMMem](https://github.com/ChenYX24/MMMem), 0 stars.
- Problem: multimodal long-term memory mostly stores and retrieves. It doesn't distill experience from finished tasks, so the same mistakes recur.
- Method: keeps multi-view memory (text, images, rendered pages) and generates synthetic scene graphs to link clues. Tasks are generated from source data. A warm-up phase consolidates knowledge into experiences in external memory, and self-training moves knowledge into the parameters. The same VLM distills each finished task into an entry of task context, conclusion and supporting links. Retrieval returns source views and related experiences per task.
- Result: on Qwen3.5-9B, relative gains over the best baseline of 36.9% (LoCoMo), 17.6% (Mem-Gallery) and 15.2% (LooGLE v2), against more than 8 baselines.

### [VideoJSON: A Minimal Harness Beats Purpose-Built Memory for Ultra-Long Video Understanding](https://arxiv.org/abs/2611.28167)
- Heat: HF 👍8 (1 day on the list, +0); code [weathon/videojson_release](https://github.com/weathon/videojson_release), 2 stars.
- Problem: agents for ultra-long video (days to weeks) rely on complex memory graphs and fixed retrieval pipelines, which limits how they can search.
- Method: at index time, a VLM turns each minute of video into one JSON record with a dense caption plus structured fields (events, entities, locations, speech transcript). At query time, a coding agent writes Python/Bash in a sandbox to filter, join and read those records, never touching raw video.
- Result: with DeepSeek V4.1 Flash it leads MAGIC-Video by 7.0 (EgoLifeQA), 20.0 (Ego-R1-Bench) and 24.75 (MM-Lifelong Week) points. Ablations show both agentic code search and structured JSON contribute. Adding hourly summaries, extra tools or video access moves the average score by less than 1.5. The abstract says code will be released after publication, but the repo already exists.

### [MORSE: Optimizing Streaming Memory Design via Open-World Auto-Research](https://arxiv.org/abs/2611.30011)
- Heat: HF 👍4 (2 days on the list, +2); no code repo.
- Problem: a streaming video system must decide what evidence to keep under limited frame storage without knowing future questions. Existing automatic harness-improvement methods can only patch with what the editor model already knows.
- Method: the editor sorts failures in training trajectories by cause, then searches papers, model cards and code for methods or pretrained perception models to borrow. When a new perception capability is added, the harness's storage and retrieval are rewritten together. It first picks changes that raise accuracy, then looks for faster ones within a tolerance.
- Result: on OvO-Bench, the Qwen3-VL-8B harness averages 0.30 s response time at 75.1% accuracy, 3.1 points above the next-best harness on the same frozen backbone.

### [Embodied-Harness: Towards Recursive Self-Improvement for Robotic Manipulation](https://arxiv.org/abs/2611.27689)
- Heat: HF 👍8 (2 days on the list, +1); no code repo.
- Problem: VLM robot agents have weakly organized memory, uncertain failure attribution and limited reuse of execution experience.
- Method: an Actor executes and a Reflector turns execution evidence into reusable manipulation guidance. Hierarchical memory separates short-term execution context from long-term experience knowledge. Failures are diagnosed from evidence, and the harness is improved over repeated attempts with no model parameter updates.
- Result: success rates of 82.4% (RoboTwin 2.0), 76.7% (RoboSPA) and 94.4% (RMBench); 96.7% average across 3 real-robot tasks.

### [Context-Grounded Skill Internalization for Vision-Language Agents](https://arxiv.org/abs/2611.30075)
- Heat: HF 👍4 (1 day on the list, +1); code [jinlinll/cgsi](https://github.com/jinlinll/cgsi), 2 stars.
- Problem: if skills are removed from the context before fine-tuning, the model learns to cite skills that no longer exist (the authors call this context misalignment, CoMi). On ALFWorld, WebShop and ARC-AGI-1, 12.2–46.0% of test trajectories show it.
- Method: a sentence detector finds the ungrounded references, and those sentences are masked or rewritten before fine-tuning.
- Result: CoMi drops by 72.5–94.6% with task success maintained. Performance matches an RL-based skill internalization baseline with far less training time.

### [RECAP: Training Long-horizon LLM Agents with Context Compaction](https://arxiv.org/abs/2611.31258)
- Heat: HF 👍1 (1 day on the list, +0); code [eth-medical-ai-lab/recap](https://github.com/eth-medical-ai-lab/recap), 1 star.
- Problem: how to learn context compression and the agent policy jointly with RL, since a summary's quality only shows many steps later.
- Method: a summary should preserve the behavior the original history induces. A "behavioral distortion" objective measures how much later behavior differs before and after compression. The gradient splits into two signals: a distortion reward for summary generation and self-distillation for the subsequent actions.
- Result: on Qwen3.5-4B, +4.6% absolute on BrowseComp-Plus and +4.3% on SWE-bench Verified, both ahead of an RL baseline that uses only the task reward. Upvotes are low, but it is a direct training method for compaction.

### [EvoViM: Recursively Self-Evolving Visual Agents for Exploration with Deferred Queries](https://arxiv.org/abs/2611.28574)
- Heat: HF 👍1 (1 day on the list, +0); code [Lewis-Xinyu/EvoViM](https://github.com/Lewis-Xinyu/EvoViM), 18 stars.
- Problem: when the question arrives only after exploration, the agent must keep visual evidence without knowing which details matter.
- Method: a frozen multimodal model turns its own interaction experience into a "visual program" that handles both memory and skills, keeps images and computes directly on pixels. As memory evolves, the same model traces failures to the operations that lost or misused evidence and edits them. It also rewrites the notes and analysis tools that guide later edits, and skips changes that already failed.
- Result: across 6 tasks, +31.3–47.6 points over the strongest baseline, AutoMem, on held-out episodes. A program written once from only the initial environment description does clearly worse.

## 🆕 New: announced last night

- [Letting Models Manage Their Own Context: Where We Stand](https://arxiv.org/abs/2611.34147) (early 👍6; repo [nvidia-nemo/labs-OO-Agents](https://github.com/nvidia-nemo/labs-OO-Agents), 2330 stars per the data): in NVIDIA's open-source harness, the model uses a context API to decide when and what to compress, compared against harness-triggered compression. Across budgets from 8K to 512K, GPT 6.1 goes from 21% to 56% on OfficeQA Pro v2 at 32K, and Kimi uses up to 41% fewer input tokens. Reusing the KV cache of the suffix left unchanged by an edit saves up to 15% prefill compute per request with no measurable accuracy change. Models differ widely in how often and when they use the API, and changing the prompt changes when compression happens. The most important context paper of the day.
- [Demystifying the Autoresearch Harness: How Context and Skills Shape Self-Evolving Agents](https://arxiv.org/abs/2611.28244) (👍4): takes the harness apart on MLE-Bench and KernelBench. For context management, keeping separately accessible history beats rolling summaries; context folding is best in all six settings, up to 19.2% above baseline. For skill management, deleting long-unused entries beats merging them or promoting them to always-on rules. Combined as MLEvolver, it reaches a 72.7% medal rate on MLE-Bench Lite.
- [Agentic LongLive: Asynchronous Agentic Memory for Long Video Generation](https://arxiv.org/abs/2611.34907) (👍16): a memory agent on a separate GPU reads only the prompts revealed so far, maintains text state and images for characters, objects and scenes, and prefills them into the generator's attention sink without blocking video generation. Persistent-state accuracy is up 26.3 points for about 1% extra time. Repo [NVlabs/LongLive](https://github.com/NVlabs/LongLive), 2910 stars, is the base repo of the series, not code specific to this paper.
- [Routing and Cache Retention for Multi-Turn LLM Inference: Theory and Implementation (PARK)](https://arxiv.org/abs/2611.34584): jointly controls routing and KV retention for multi-turn agents. On 16 H200s, output throughput is 24.2% above the strongest baseline on SWE trajectories and 40.0% on Terminal-Bench. On a single replica, a retention index cuts prefix token loss from 13.26% to 2.17%.
- [Latent-in-the-Middle: On the Security of Cross-Model Latent Communication in Multi-Agent Systems](https://arxiv.org/abs/2611.34278): passing KV cache between models through a mapper weakens safety alignment. A target model that natively follows only 0.4% of prompt injections follows up to 44.2% after the mapper transfer. The paper also proposes a target-side cache guard as mitigation.
- [What Does Skill Lift Actually Measure? A Source-Code-Level Audit of SkillsBench](https://arxiv.org/abs/2611.33943): audits SkillsBench and analyzes 7,554 public trials. Three tasks have grader dependencies or definition gaps, and 4 more contain placeholder skill directories. After multiple-testing correction, no task shows a significant negative skill effect, so the claim that skills hurt does not hold.
- [VibeVideoAgent: Closing the Perceptual Loop for Code-Driven Video Generation](https://arxiv.org/abs/2611.34237) (👍54): runs multimodal perception in a short-lived context isolated from the coder and returns only compact Findings, so rendered frames don't blow up the long-horizon context. Across 239 tasks, Claude Opus 5.5's L3 score goes from 4.03 to 4.43.
- [SEEK: Self-Evolution through Execution Knowledge for Agentic Robot Manipulation](https://arxiv.org/abs/2611.33915) (👍10): uses executable program policies plus a Persistent Action-Effect Bank to keep execution knowledge across attempts. On RoboDojo, success after ten attempts goes from 19.7% to 48.0%, with 77.6% fewer model requests under GPT-6.2 Astra.
- [RoboEvo²: Recursive Robot Self-Improvement via Harness-Policy Co-Evolution](https://arxiv.org/abs/2611.34675) (👍9): harness and policy evolve each other, with experience distilled into skills, a routing policy and experience memory. Standalone success on LIBERO-PRO goes from 11.0% to 84.1%.
- [EgoUseBench: Benchmarking Computer-Use Agents under Evolving First-Person Contexts](https://arxiv.org/abs/2611.34466) (👍18): 693 tasks built from 74 hours of first-person video. Online Ego Use averages 26.3% lower success than ordinary Computer-Use.
- [DFly2: Turbocharging Long-Context Speculative Decoding by Sharing the Target's Sparsity](https://arxiv.org/abs/2611.34776): the draft model shares the target model's KV and sparsity selection instead of keeping its own cache. On long-context and agentic workloads, its accepted-token advantage over a stronger baseline widens to 10.0%–31.5%.
- [MINE: A Training-Free Defense against Indirect Prompt Injection](https://arxiv.org/abs/2611.34188): a training-free, query-conditioned reranking based on mutual information and embedding variance, defending against indirect prompt injection. It also covers injection through agent tool calls (InjecAgent).

## Observations

- Models managing their own context, with inference engines following: NVIDIA's paper and the Autoresearch ablation agree that retrievable history beats summarizing and merging. The same day brought inference-side work on KV cache edit reuse (15% prefill savings), KV retention for multi-turn agents (PARK) and cache-sharing speculative decoding (DFly2).
- Self-evolving harnesses and memory, with no weight changes: Embodied-Harness, ReWeave, SEEK, RoboEvo², MORSE and EvoViM all use the same mechanism of turning failure evidence into a rewritten harness or memory program. Robotics is especially crowded, and several robot harnesses are evaluated on RoboDojo.
- Heat and "context" don't line up: the top upvoted hot papers are computer-use perception (NightWatch), RL training (RLVB) and robot coding agents (ACAP). Context papers have low upvotes and small gains. Only NVIDIA's paper has high early heat in the new list, and its 2330 stars are the harness repo's.
- Evaluation reliability is under question: the SWE-Gym reward-label audit (74% of "unsolved" tasks may have faulty tests) and the SkillsBench source-code audit both check whether the benchmark itself can be trusted. CUA-SEE takes the self-evolving evaluation route.
