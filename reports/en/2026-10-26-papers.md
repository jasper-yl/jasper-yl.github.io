### [Retrieval Augmented Generation Compositionality](https://arxiv.org/abs/2610.29722)
- Heat: HF 👍54 (listed 4 days, +29; 25 when first seen); code [dolev31/lasagna](https://github.com/dolev31/lasagna) 20★; no X data.
- Problem: Each technique in a RAG pipeline (embedding, chunking, retrieval, reranking, query expansion, context compression, agentic verification) is evaluated alone, so it's unknown whether the gains survive when combined.
- Method: An open-source framework, LASAGNA, for controlled evaluation. It declares 3 hypotheses up front and tests 450 configurations across 8 benchmarks, with corpora of 5K–200K documents.
- Findings:
  - Three retrieval techniques were predicted to add +47% together; stacked, they gave only +17%.
  - The best combination for retrieval quality differs from the best for answer faithfulness, so optimizing one can hurt the other.
  - The best combination changes as the corpus grows.
  - The authors call for testing new RAG techniques inside full pipelines.
- Take: The most solid "engineering warning" of the day, with concrete numbers, so it goes first.

### [Memory-Centric Continual Learning for AI Agents](https://arxiv.org/abs/2610.29357)
- Heat: HF 👍43 (listed 4 days, +24; 19 when first seen); no code repo; no X data.
- Problem: External memory is mostly treated as a passive retrieval cache, judged on whether it can recall facts and not on whether it supports continual learning.
- Method: MCCL has three parts.
  - A three-axis taxonomy: where state lives (substrates), what form it takes (assets), and how it is managed (policies).
  - An evaluation protocol measuring retention under interference, adaptation to change and task transfer, to separate real behavioral gains from mere context expansion.
  - A memory scaling framework modeling how performance varies with experience, storage capacity and compute.
  - An inner loop updates memory state; an outer loop improves the management policy from task feedback.
- Finding: Memory should be judged by whether it improves future actions. This is a position/survey paper, and the abstract has no experimental numbers.

### [MemPilot: Orchestrating On-Demand Multimodal Memory Curation for LLM Agents](https://arxiv.org/abs/2610.06830)
- Heat: HF 👍41 (listed 4 days, +5); code [ViktorAxelsen/MemPilot](https://github.com/ViktorAxelsen/MemPilot) 7★; no X data.
- Problem: Most agent memory is built at write time in a query-agnostic way, which costs preprocessing and can drop details that only later turn out to matter.
- Method: An RL-trained multi-step policy chooses at each step between retrieving from query-agnostic memory and handing the raw multimodal history to a different LLM/VLM for query-specific curation. The policy also controls how much evidence to use, the curation instructions, model choice and whether to look at images. Training estimates advantages per objective before aggregating, and uses prefix marginal-utility estimates for multi-step credit assignment.
- Finding: On 5 multimodal agent-memory benchmarks, its performance-cost-latency frontier is wider than that of existing trade-off-aware baselines.

### [Socratic Skill Learning: Interleaving Teaching and Practice for Transferable Agent Skills](https://arxiv.org/abs/2610.17860)
- Heat: HF 👍49 (listed 4 days, +19); code [NJU-LINK/Socratic-Skill-Learning](https://github.com/NJU-LINK/Socratic-Skill-Learning) 2★; no X data.
- Problem: One successful task attempt may never test a Skill's conditions of applicability, so a learned Skill may not transfer.
- Method: SSL alternates teaching by an expert Educator with practice by a Student. The Student is the only role that operates the environment and the only one that writes Skills, and it can question, test and revise the Educator's suggestions. The authors built SkillTransferBench (35 task families, 408 executable cases) to test reuse. An improved Issue-Guided SSL tracks unresolved issues across Skill revisions to pick and focus reviews.
- Finding: On the main cohort, Fixed-Window SSL scores 0.801 utility, against 0.723 with no Skill, 0.761 for Trace2Skill and 0.751 for SKILL-KD. Issue-Guided SSL reaches 0.805 with 61.7% fewer Educator tokens and 16.9% fewer total acquisition tokens.

### [Building AI Research Teams for Autonomous Discovery of Linear Attention Architectures](https://arxiv.org/abs/2610.28887)
- Heat: HF 👍45 (listed 4 days, +29; 16 when first seen); no code repo; no X data.
- Problem: When several AI researchers collaborate under a limited experiment budget, how do they learn from each other's findings without settling too early on a local optimum?
- Method: A persistent team of AI researchers, each with a different disciplinary background, a private research history and shared experimental evidence, and research opportunities assigned adaptively.
- Findings:
  - Searching for linear attention architectures, the team beats GDN2 on 1.3B-scale language modeling, commonsense reasoning, and synthetic and real retrieval tasks.
  - In ablations, removing any organizational component clearly weakens it: without disciplinary backgrounds the search stalls early, without private histories progress drops, and uniform selection is worse than adaptive allocation.
- Take: Included under Context because the private-memory vs. shared-evidence ablation gives a direct result.

### [DLite: History-free Speculative Decoding for Agentic AI](https://arxiv.org/abs/2610.23787)
- Heat: HF 👍36 (listed 3 days, +3); code [SJTU-DAI-Sys/DLite](https://github.com/SJTU-DAI-Sys/DLite) 49★; no X data.
- Problem: Agent workloads have long, evolving contexts. Draft models in existing speculative decoding lose up to 80% of their acceptance length, and keeping the draft model's historical KV cache adds large system overhead.
- Method: It traces both problems to the same source, the ever-growing history context. DLite reuses the target model's contextual hidden states and makes only local speculative predictions, without maintaining history explicitly. A lightweight sequential head restores causal dependencies within a block, with a two-stage training recipe.
- Finding: On general, long-context and agent workloads, acceptance length is 2–6, up to 70% higher than DSpark, the strongest speculative decoding method.

### [DeltaStreamer: Towards Human-Like Agentic Streaming Video Understanding](https://arxiv.org/abs/2610.19849)
- Heat: HF 👍38 (listed 3 days, +0); code [BBBBchan/DeltaStreamer](https://github.com/BBBBchan/DeltaStreamer) 87★; no X data.
- Problem: Streaming video understanding has to keep evidence without knowing what will be asked. Existing compression blurs event transitions, drops detail, and can't recover it.
- Method: It watches the stream before any query arrives and writes visual changes explicitly into a structured "change-aware memory". When a query arrives, a query-driven planner decides what evidence is needed, guiding memory retrieval and targeted replay of past frames.
- Finding: 66.07% overall on OVO-Bench and 59.53% on StreamingBench, ahead of representative streaming-video methods.

## 4. 🆕 New: announced last night
- [MemCryst: Lifelong Context Adaptation through Bidirectional Memory-Skill Learning](https://arxiv.org/abs/2610.32295): freezes the model and lets memory and Skills learn from each other. Recurring fragments in memory create or revise Skills, Skill-guided interaction produces new memories, and task outcomes reweight the retrieved records. On ALFWorld, success is 63.17% with both, 59.83% with memory only and 50.50% with Skills only. Code: [tianyi0216/Memcryst](https://github.com/tianyi0216/Memcryst).
- [ActionRAG](https://arxiv.org/abs/2610.32752): a graph-memory architecture that does careful entity resolution at index time and re-scores triples at query time with diffusion over local graph paths. On MemoryAgentBench, average accuracy is 55.1, 5.4 points above the strongest retrieval-based memory baseline.
- [Agentic Memory Management Is the Next Frontier of Information Retrieval](https://arxiv.org/abs/2610.32464): a position paper arguing agent memory management is a natural extension of IR research. It proposes a taxonomy that sorts memory objects into constants, functions and operators, plus a research agenda.
- [When Agents Fail: Model or Harness--Who's to Blame?](https://arxiv.org/abs/2610.32483): evaluates harness-model interaction with 5 metrics across 4 general-purpose harnesses (OpenCode, Codex CLI, Pi CLI, DeepAgents) and 4 models, 111 settings and 52,168 trajectories. Harness rankings vary with model and benchmark; OpenCode ranks first across models.
- [Tool-Calling LLM Agents Under Realistic MCP Faults](https://arxiv.org/abs/2610.32555): MCP-Injector is a protocol-aware fault-injection middleware, with fault distributions drawn from 57,240 issues/PRs across 1,774 MCP repos. Injected faults drop the task completion score from 8.08 to 3.23 (−60%). Fault tolerance does not differ significantly between 20B and 120B models; differences between agent frameworks are larger.
- [LeafSkill](https://arxiv.org/abs/2610.32412): adds an external reuse layer for recursive agents. It retrieves leaf-level action-grounding experience, and a 1.7B selector decides whether to use it directly or hand back to the original agent. On 200 Robotouille tasks, success is 68.5% against 60.5% for ReCAP, with 14.42% fewer tokens on tasks both complete.
- [CASE: Confusion-Aware Skill Evolution for Frozen Multimodal Emotion Models](https://arxiv.org/abs/2610.32481): keeps a sparse, self-evolving library of "easily confused emotion pair" Skills for multimodal emotion recognition, retrieves the matching Skill at inference and leaves the backbone frozen. Qwen3-VL-8B goes from 46.80% to 59.13% on CA-MER.
- [RSIHub: A Composable Framework for Agent-Evolution Methods](https://arxiv.org/abs/2610.32253): an open-source framework that reproduces AHE, Hyperagents, A-Evolve and GEPA on shared infrastructure. Method rankings change with the setting, optimization gains don't always transfer to held-out tasks, and the largest pass@1 gain is 13.5 points (initial 👍32, code [simple-agent-lab/RSIHub](https://github.com/simple-agent-lab/RSIHub) 198★).
- [HiSTEVE 1.0](https://arxiv.org/abs/2610.31162): a hierarchical VLA agent for Minecraft whose harness has structured memory for tracking progress and a VLM planner. It scores 85.0% on MineStudio Bench and 37.4% average success on OpenHA (initial 👍37).
- [4DMemory](https://arxiv.org/abs/2610.32332): a long-horizon spatiotemporal memory benchmark with about 900 hours of video and 5,000+ questions. Its 4DMemory Harness (4 Skill types, 22+ tool models, retrieval augmentation) lifts all 13 models by over 50%; the same models score over 10% lower on the new benchmark than on older ones.
- [DraMaze](https://arxiv.org/abs/2610.32002): a multi-agent pipeline for writing micro-drama scripts that uses a "backward narrative dependency tree" to organize and retrieve history memory by future plot goals. On 60-episode scripts, repeated causal patterns fall 32.1% and the Logic score is 82.5, 8.5 points above the best baseline (initial 👍8).

## Research trends

- Memory research is moving from "how to store and retrieve" to "how to judge and curate on demand". MCCL proposes judging memory by whether it improves future actions, MemPilot turns curation into a tunable performance-cost-latency policy, and RAG Compositionality warns that individual gains don't simply add. New papers ActionRAG, MemCryst and Agentic Memory Management follow the same line.
- Harness self-evolution appears at both ends of the board. The hot list has Self-HPO, HarnessPro and Terminal-RSI, rising has Self-Evolving Agent Harness, and last night brought RSIHub and When Agents Fail. Self-HPO's joint gain exceeds the sum of the separate gains, while RSIHub finds optimization gains don't always transfer, so the two are worth reading together.
- Skills are increasingly studied as external context assets: Socratic Skill Learning, LeafSkill and CASE all keep the Skill library separate from model parameters. On the engineering side, open harness and framework projects such as OpenGCUA (441★), Self-Evolving Agent Harness (387★) and RSIHub (198★) are drawing attention over the same period.
- Environment and benchmark synthesis remains the mainstream in the other-Agent category: CoworkEnv, Interlock, MAI-Gym, AdaExploreBench and OR-License all address how to get verifiable training or evaluation tasks. Most evaluation findings end in "a clear gap remains", for example no model matches the experts on OR-License.
