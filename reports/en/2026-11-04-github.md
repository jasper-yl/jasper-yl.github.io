## Agent Context: what people are building

### Knowledge graphs, ontologies and codebase indexing

Gives agents a structured graph, instead of whole-repo text or raw tables, to understand code and data. Code graphs are growing steadily. Today's new angle is enterprise data ontologies.

- [NVIDIA/auto-ontology](https://github.com/NVIDIA/auto-ontology) · ⭐4,280 · +2,057/day
  - Approach: builds a graph-based semantic reasoning layer over data and generates queries deterministically, to improve context retrieval for LLMs and agents.
  - Growth: small bumps of +62, +189 and +143 on Oct 25 to 27, then +392 on Nov 2 and +2,323 on Nov 3.
  - Background: per [AlphaSignal](https://alphasignal.ai/news/nvidia-s-auto-ontology-stops-ai-agents-from-querying-the-wrong-data), it is an Apache-2.0 framework that adds a semantic layer over enterprise databases so agents write more reliable SQL, and it is exposed to agents through an MCP server and a REST API. The "90% less time to build an ontology" figure is the vendor's own test, reported by [BestHub](https://www.besthub.dev/articles/nvidia-s-auto-ontology-cuts-ontology-build-time-90-semantic-layer-for-data-agents-aed30070bac2). (verified: [AlphaSignal](https://alphasignal.ai/news/nvidia-s-auto-ontology-stops-ai-agents-from-querying-the-wrong-data))
- [Graphify-Labs/graphify](https://github.com/Graphify-Labs/graphify) · ⭐142,274 · +625/day: turns code, docs, SQL schemas, configs and PDFs into a queryable knowledge graph. It uses local deterministic AST parsing, explains every edge and needs no vector store. 18 days running.
- [Egonex-AI/Understand-Anything](https://github.com/Egonex-AI/Understand-Anything) · ⭐90,509 · +299/day: turns any codebase into an interactive knowledge graph you can explore, search and ask questions of.

## Observations

1. Computer use is moving from the browser to desktop and phone.
   - Desktop: agent-desktop (accessibility tree), which went from 3 a day to its peak in 5 days. The peak has passed.
   - Phone: Mika (on-device Android) and phone-harness/mcp (connects real iPhones and Android phones).
   - The long-running base layer is cua, 47 days in the steady-growth table.
   - Basis: agent-desktop was released Oct 31, and the jump in the data matches the release date (verified: [Born City](https://borncity.com/news/agent-desktop-1-0-2-vercel-labs-steuert-mac-windows-und-linux-ohne-screenshots/)).
2. REA ("reverse engineer anything") has become a scene of its own.
   - The main repo [morluto/rea](https://github.com/morluto/rea) is cooling but still No. 1.
   - Spinoff skills such as rea-video appeared, which got +508 today.
   - [qybaihe/bla](https://github.com/qybaihe/bla) goes the other way, on defense against REA-style reverse-engineering agents: ⭐2,200, +152/day.
3. The DeepSeek Harness (dsh) ecosystem is expanding mainly through plugins.
   - deepseek-harness has 23 days running and dsh-our-free-model 31. [Fei2411/DS-Bot](https://github.com/Fei2411/DS-Bot) is at +260/day with 25 days running, and [liguobao/ds-harness-remote](https://github.com/liguobao/ds-harness-remote) is at +233/day. The rising star Deepscient belongs to the same ecosystem.
   - Coverage includes model supply, multi-bot collaboration, remote access and scientific research.
4. Big companies are placing many bets on skills and the context layer, and the context layer is extending from code to data.
   - NVIDIA (auto-ontology, SkillSpector), Google (elephant-goldfish-model), Cloudflare (security-audit-skill), Microsoft (TokenEconomizer) and Vercel (agent-desktop) all charted at once.
   - auto-ontology and [HelixDB/helix-foundry](https://github.com/HelixDB/helix-foundry) (⭐2,039, +28/day, lets agents draft an ontology and load it into a graph database) show knowledge graphs no longer serve only code.
   - helix-foundry's growth is modest, so we draw no further conclusion from it.
