### Codebase and data indexing: knowledge graphs and semantic layers
These tools let an agent retrieve context from a structured graph or ontology instead of stuffing in raw text. NVIDIA's semantic layer is the biggest mover today.

- [NVIDIA/auto-ontology](https://github.com/NVIDIA/auto-ontology) · ⭐10,898 · +790/day: builds a graph-based semantic reasoning layer over data, enabling deterministic query generation and better context retrieval. +10,176 in 7 days, peaked at +2,462 on 11-04, then fell back to +485 / +768.
- [Graphify-Labs/graphify](https://github.com/Graphify-Labs/graphify) · ⭐144,869 · +536/day: turns codebases, docs and SQL schemas into a queryable knowledge graph using local deterministic AST parsing and no vector store. It plugs into Claude Code, Cursor and Codex as a /graphify skill.
- [Egonex-AI/Understand-Anything](https://github.com/Egonex-AI/Understand-Anything) · ⭐91,716 · +280/day: turns any code into a knowledge graph you can explore, search and query.

[NVIDIA/SkillSpector](https://github.com/NVIDIA/SkillSpector), a scan-before-you-install tool, has grown steadily for 70 days, so security review of skills is becoming a companion need.
- **Two kinds of spikes.** [meta/astryx](https://github.com/meta/astryx) (+3,017 in one day) and [NVIDIA/auto-ontology](https://github.com/NVIDIA/auto-ontology) (+2,462 on 11-04) jumped once and fell back. [morluto/rea](https://github.com/morluto/rea), [stablyai/orca](https://github.com/stablyai/orca) and [deepseek-ai/deepseek-harness](https://github.com/deepseek-ai/deepseek-harness) have grown for dozens to over a hundred days, and should be read separately. Among new repos, the one-day jumps of [0sec-labs/0](https://github.com/0sec-labs/0) and [codepawl/67.js](https://github.com/codepawl/67.js) have no visible source of traffic in the data, so treat them as reference only.
- **Spin-off clusters form around one hot project.** REA produced lists, defenses and video/animation reverse-engineering projects. dsh produced compression, remote-access and bot-team plugins. "Anti-AI-slop design" also has several parallel repos. The ecosystem is converging on one core plus many plugins and skills.
- **In context tooling, the momentum is in structure and cost.** Knowledge graphs and semantic layers ([NVIDIA/auto-ontology](https://github.com/NVIDIA/auto-ontology), [Graphify-Labs/graphify](https://github.com/Graphify-Labs/graphify)) and cost control ([microsoft/TokenEconomizer](https://github.com/microsoft/TokenEconomizer), [JuliusBrussee/caveman](https://github.com/JuliusBrussee/caveman), [ranxianglei/billion-context](https://github.com/ranxianglei/billion-context)) are rising together. Memory projects [thedotmack/claude-mem](https://github.com/thedotmack/claude-mem) and [vectorize-io/hindsight](https://github.com/vectorize-io/hindsight) have fallen from their peaks to steady growth.
