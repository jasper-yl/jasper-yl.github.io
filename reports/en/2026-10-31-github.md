## 1. Agent Context: what features people are building

### Cost and token control
Trend: the focus is moving from compressing output to learning from past sessions and trimming waste. Microsoft's official project showed up today.

- [microsoft/TokenEconomizer](https://github.com/microsoft/TokenEconomizer) 🆕 · ⭐2,712 · +1,368/day
  - A plugin for Claude Code, Codex, Copilot CLI and Pi. It changes neither the model nor your code.
  - It learns "micro-skills" from a repo's past sessions (for example, the correct test command) and injects them at session start once confirmed across 3 sessions.
  - It stops sending tools that haven't been used in a long time with every request.
  - A failure-loop guard gives one redirect hint when a judge model is at least 70% confident the agent is stuck.
  - The author reports average cost on SWE-Bench down 18.4–30.9%. Pass@1 rose in 4 of 5 agent×model combinations and fell 1.0 point in one (Opus 4.8) (verified: [repo README](https://github.com/microsoft/TokenEconomizer)). These are the author's own measurements, not independently verified.
- [JuliusBrussee/caveman](https://github.com/JuliusBrussee/caveman) · ⭐116,466 · +204/day: a skill plus proxy that makes the model "talk like a caveman", claiming 65% token savings.
- [cheaper-inference/OmniRoute](https://github.com/cheaper-inference/OmniRoute) · ⭐83,087 · +311/day: a free AI gateway with quota-aware automatic fallback and built-in RTK+Caveman compression, claiming 15–95% token savings. On a 125-day streak.

## 4. Observations
- Computer use is spreading from cloud browsers to phones and native desktop UIs. Today's chart has a phone agent (Mika), accessibility-tree desktop control (agent-desktop), a bot with a VM (OpenMausBot), and a computer for every AI coworker ([CopilotKit/OpenBot](https://github.com/CopilotKit/OpenBot)).
- Cost control is moving from compressing wording ([caveman](https://github.com/JuliusBrussee/caveman), [OmniRoute](https://github.com/cheaper-inference/OmniRoute)'s compression) to automatic trimming based on past experience ([TokenEconomizer](https://github.com/microsoft/TokenEconomizer)). Growth in this area picked up over the last 3 days once a big company entered.
- The ecosystem is gathering around DeepSeek Harness (dsh). Many projects on the chart carry the dsh or deepseek-harness tag: [deepseek-harness](https://github.com/deepseek-ai/deepseek-harness) itself, [dsh-baton](https://github.com/JialaoLiu/dsh-baton), [Deepscient](https://github.com/yzlin286-wq/Deepscient), agent-purge, DS-Bot and others. Several cross-agent management layers ([orca](https://github.com/stablyai/orca), [magpie](https://github.com/yetone/magpie), [paperclip](https://github.com/paperclipai/paperclip), [squadra](https://github.com/dagoSte/squadra), [Orkas](https://github.com/Orkas-AI/Orkas)) all sell the ability to plug into Claude Code, Codex, OpenCode and more at once.
- [rea](https://github.com/morluto/rea) and [bla](https://github.com/qybaihe/bla) form a "reverse-engineering agent vs. anti-reverse-engineering" pair, which makes reverse engineering the hottest vertical agent use case right now. rea's 28-day average of 14,738 is well above its 7-day 5,628, so it is cooling but still first on the chart.
