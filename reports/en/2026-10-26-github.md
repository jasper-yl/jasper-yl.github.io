## Agent Context: what people are building

### Codebase indexing, knowledge graphs, local retrieval

Agents grep blindly through big repos and burn tokens. The common pattern is local-first, deterministic parsing, delivered over MCP or as a Skill. The two projects flagged as fading yesterday both rebounded, so the right read is volatility, not decline.

- [Graphify-Labs/graphify](https://github.com/Graphify-Labs/graphify) · ⭐135,861 · +993/day: deterministic local AST parsing turns code, docs, SQL, configs and PDFs into a queryable knowledge graph. Every edge is explainable and there is no vector DB. Yesterday +632 (see the 10-25 report).
- [xerj-org/xerj](https://github.com/xerj-org/xerj) · ⭐16,755 · +1294/day: a single Rust binary serving hybrid BM25 + vector search over MCP, compatible with the Elasticsearch API. It covers both agent memory and RAG, and "Corpus Hub" supplies ready-made corpora. Yesterday +255 (see the 10-25 report); +7637 on this week's Trending.
- [dzhng/jevgrep](https://github.com/dzhng/jevgrep) · ⭐2,909 · +10/day: a CLI that finds relevant files by what the code does.

### Long-term memory and cross-agent handoff

This category fixes agents forgetting between sessions, and lets agents from different vendors share memory. Several projects grew faster than yesterday.

- [vectorize-io/hindsight](https://github.com/vectorize-io/hindsight) · ⭐54,036 · +412/day (yesterday +267): agent memory that learns.

## Observations

- The tooling layer is about managing several agents side by side. orca, herdr, tuios, facadecode, pandacode, SOMA and nuphos all put multiple Claude Code, Codex and similar agents in one interface. Four of today's 10 sustained-breakout projects fit (facadecode, pandacode, SOMA, openfilm). The demand is for managing existing agents, not building new ones.
- The dsh and dsh-plugin topic tags cover a lot of ground. Projects carrying them include rea, dsh-our-free-model, deepseek-harness, billion-context, archify, ruflo, ai-engineering-from-scratch and answer-me-with-html. rea is first on the chart, yet its topics also include `dsh` and `touhou`, which have nothing to do with reverse engineering. A topic tag alone doesn't show a real tie to dsh, so treat the star totals with care.
- Yesterday's call that the retrieval layer was fading is reversed. xerj (+255 → +1294) and graphify (+632 → +993) were just fluctuating day to day. Compression projects (billion-context, caveman) were flat or falling.
- Security Skills are still strong but uneven. security-audit-skill is at +1898/day, down 31% from +2744. NVIDIA/SkillSpector is flat at +312 (yesterday +334). rea (reverse engineering) and awesome-reverse-engineered are both in sustained breakout, so the security and reverse-engineering line is heating up as a whole, not just Cloudflare.
- No obvious star-farming projects found. One caution: dsh-our-free-model is promoted on "free and unlimited" with 44,518 stars and +1873/day. The claim is unverified, and no web verification was done.
