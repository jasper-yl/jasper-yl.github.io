## What people are building in Agent Context

### Long-term memory / cross-session context
Agents start every session from zero. These tools record, compress, then re-inject. claude-mem grew about 5x in four days; the others are steady.

- [thedotmack/claude-mem](https://github.com/thedotmack/claude-mem) · ⭐110,418 · +1,635/day: records everything the agent does in a session, compresses it with AI and injects it into future sessions. Works with Claude Code, Codex, Gemini, OpenCode and others. It ran about 180–340/day for 10 days, then 975 → 1,630 → 1,524 → 1,764.
- [vectorize-io/hindsight](https://github.com/vectorize-io/hindsight) · ⭐58,028 · +489/day: "agent memory that learns." 43 days running above the threshold; 30-week peak 4,601 on 09-27.
- [akitaonrails/ai-memory](https://github.com/akitaonrails/ai-memory) · ⭐14,915 · ≈+197/day (Trending weekly +1,378 ÷ 7): long-term memory for coding-agent CLIs, built for handoffs between agent vendors.

### Context compression / tool-output trimming / token cost
Tool output and long conversations blow out the context window and burn tokens. New today: a Microsoft "black-box" cost-control project that leaves the agent itself untouched.

- [microsoft/TokenEconomizer](https://github.com/microsoft/TokenEconomizer) 🆕 · ⭐4,409 · +766/day: "experience-driven black-box cost control" for coding agents such as Claude Code, Codex and Copilot. Last 3 days: 1,510 → 969 → 908; +4,179 over 7 days.
- [mksglu/context-mode](https://github.com/mksglu/context-mode) · ⭐33,245 · +145/day (from Trending today): a local plugin that keeps tool output out of the context, stores it in a sandbox and retrieves it with SQLite FTS5. Claims a 99% cut in context bytes.
- [cheaper-inference/OmniRoute](https://github.com/cheaper-inference/OmniRoute) · ⭐83,875 · +383/day: a free AI gateway that claims 375 providers behind one endpoint, with quota-aware fallback and RTK+Caveman compression (claims 15–95% token savings). 127 days running above the threshold.

## Observations

- Skills remain the bulk of the growth and have split into two lines: design taste ([Nutlope/hallmark](https://github.com/Nutlope/hallmark), [pbakaus/impeccable](https://github.com/pbakaus/impeccable), [Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill)) and engineering method ([google/elephant-goldfish-model](https://github.com/google/elephant-goldfish-model), [mattpocock/skills](https://github.com/mattpocock/skills), [obra/superpowers](https://github.com/obra/superpowers)). Google, Cloudflare, NVIDIA and Microsoft are all publishing official skills or tools, so big vendors are treating the skill format as a distribution channel.
- Cost and context management is turning into products. [microsoft/TokenEconomizer](https://github.com/microsoft/TokenEconomizer), [mksglu/context-mode](https://github.com/mksglu/context-mode) and the compression feature in [cheaper-inference/OmniRoute](https://github.com/cheaper-inference/OmniRoute) all cut token or context use. [thedotmack/claude-mem](https://github.com/thedotmack/claude-mem) grew about 5x in four days, so demand for memory is still strong.
- Ecosystem clusters are forming around single hits. REA is one: the main repo, two awesome lists and the defense tool [qybaihe/bla](https://github.com/qybaihe/bla). DeepSeek Harness plugins are another: [deepseek-ai/deepseek-harness](https://github.com/deepseek-ai/deepseek-harness) itself plus [JialaoLiu/dsh-baton](https://github.com/JialaoLiu/dsh-baton), [yzlin286-wq/Deepscient](https://github.com/yzlin286-wq/Deepscient), DS-Bot, dsh-desktop and others, all tagged dsh-plugin or deepseek-harness. The "open-source alternative to Grok Bot" pitch appears in the descriptions of both [milind-soni/OpenMausBot](https://github.com/milind-soni/OpenMausBot) and Codync.
- Computer use is moving from pixels to structured UI data. [vercel-labs/agent-desktop](https://github.com/vercel-labs/agent-desktop) uses the accessibility tree, [wangzan101/Mika](https://github.com/wangzan101/Mika) uses Android's accessibility service, and [reacher-z/Awesome-CUA](https://github.com/reacher-z/Awesome-CUA) has become a directory for the space.
- A side note: a cluster of projects uses Claude Code to debloat TVs (cleanyourtv at +1,330/day, plus cleanyourtv-app, free-my-tv and tv-detox). They have only a weak link to the core agent theme.
