## 1. Agent Context: what features people are building

### 1. Context compression / tool output trimming / token cost
These address tool output, logs, and RAG snippets crowding the context window and driving up token costs. Headroom and context-mode are both on the list, and both compress or sandbox content before it reaches the model.

- [headroomlabs-ai/headroom](https://github.com/headroomlabs-ai/headroom) — stars 77,537 · today +552 — Compresses tool output, logs, files, and RAG snippets before they reach the LLM, available as a library, proxy, or MCP server. The project claims about 20% token savings for coding agents and 60–95% for JSON.
- [mksglu/context-mode](https://github.com/mksglu/context-mode) — stars 31,806 · +2,968 this week — Puts tool output in a sandbox (claims a 98% reduction), persists session memory, and covers 17 platforms via MCP + hooks.

## 4. Observations

1. **Context engineering is moving from "prompting tricks" to infrastructure**: compression (Headroom, context-mode), retrieval (Graphify, xerj, jevgrep), and memory (ai-memory, engram, agent-beacon) all appear on the list at once. Most plug in via MCP, hooks, or skills, and they stress running locally.
2. **Skill / plugin standards are converging across harnesses**: many projects list Claude Code, Codex, Cursor, Gemini CLI, and others together in their descriptions, and the official directories (Anthropic, Cursor, Vercel) had sizable gains this week. These projects look more like a distribution layer and are no longer tied to a single agent.
3. **"Management layer" tools around agents are heating up**: Orca, harp, coucou, worktrunk, and magpie address parallel multi-agent work, approval notifications, worktree isolation, and model switching. This suggests users are already running multiple agents at once, and the bottleneck has shifted from individual agent capability to scheduling and attention.
4. **Security and vertical agents show a clear hotspot**: security-audit-skill has the highest gain today, and pentagi, ARTEX, rea, and a batch of reverse engineering projects are all trending. Note that today's data has no historical snapshot and rea's unusual gain could not be verified, so these judgments reflect only today's list, not a sustained trend.
