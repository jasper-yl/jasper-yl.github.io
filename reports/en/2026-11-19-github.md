## Agent Context: what features people are building

### Codebase indexing and long-term context

Lets a coding agent get a persistent map of the code instead of rereading the whole repo before each edit. Older knowledge-graph projects keep growing steadily; a new indexing project had a one-day jump.

- [aoci-spec/aoci-code](https://github.com/aoci-spec/aoci-code) · ⭐2,584 · +545/day: a local-first MCP server and CLI written in Go. It builds a Git-tracked persistent index of the whole codebase and database schema, which Claude Code, Codex, Cursor and opencode read before editing. It got 2–10 stars a day for 13 days, then +502 yesterday: a one-day spike.
- [Graphify-Labs/graphify](https://github.com/Graphify-Labs/graphify) · ⭐150,494 · +463/day: turns code, docs, SQL schemas and PDFs into a queryable knowledge graph. It uses local, deterministic AST parsing, explains every edge and uses no vector store. The 7-day average has met the threshold for 33 days straight.

### Output trimming and token cost

Compresses model answers and tool output to save tokens. These projects grow slowly and steadily rather than in bursts.

- [JuliusBrussee/caveman](https://github.com/JuliusBrussee/caveman) · ⭐121,487 · +242/day: a skill plus local proxy that makes answers shorter and tool output smaller. The original text stays recoverable.
- [cheaper-inference/OmniRoute](https://github.com/cheaper-inference/OmniRoute) · ⭐88,866 · +264/day: an AI gateway with one endpoint for 375 providers and quota-aware automatic fallback. It claims its RTK+Caveman compression saves 15–95% of tokens. Daily gains have met the threshold for 144 straight days.

### Skills ecosystem and quality control

There are more and more skills, and they need official specs, evals and security checks. The official spec repo keeps growing, and evaluation tooling for skills is starting to appear.

- [anthropics/skills](https://github.com/anthropics/skills) · ⭐197,586 · +514/day: the official public repo for Agent Skills.
- [NVIDIA/SkillEvaluator](https://github.com/NVIDIA/SkillEvaluator) · ⭐4,041 · +480/day: a multi-layer eval framework with quality gates, security scanning, semantic-overlap detection, synthetic eval sets and real-agent evals, plus reusable CI templates. It has met the daily threshold for 8 days. The first 6 days were 3–9 stars a day, then it climbed.
- [cursor/plugins](https://github.com/cursor/plugins) · ⭐17,477 · +370/day: Cursor's plugin spec and official plugins. Daily gains have met the threshold for 93 days, and the last 3 days (303 → 357) show it speeding up.

### Reaching the outside world (CLIs, web, desktop, fresh knowledge)

Agents need current information and a way to operate existing software. Two directions run in parallel: turning software into agent-callable CLIs, and keeping agent knowledge current.

- [HKUDS/CLI-Anything](https://github.com/HKUDS/CLI-Anything) · ⭐60,344 · +865/day: aims to make all software natively usable by agents, with a companion CLI-Hub. It got 29–124 a day for 11 days, then 124 → 379 → 811 over the last 3.
- [GoogleChrome/modern-web-guidance](https://github.com/GoogleChrome/modern-web-guidance) · ⭐23,283 · +611/day: keeps coding agents current on modern web best practices. It peaked at 4,134 on 11-14 and fell to 690 yesterday, a typical pulse-then-decay.

### Vertical skill packs (design taste, video, migration, security)

## Observations

- Skills are most of today's growth. Mature general-purpose skill repos (superpowers, [anthropics/skills](https://github.com/anthropics/skills), ECC, mattpocock/skills) still add 500–2,000 a day. New growth is concentrated in design taste and make-video-with-code (numbers in the highlights).
- Official and big-company teams have started building evals and specs for skills: NVIDIA's [NVIDIA/SkillEvaluator](https://github.com/NVIDIA/SkillEvaluator) and [NVIDIA/SkillSpector](https://github.com/NVIDIA/SkillSpector) (the latter in the steady-growth table), [cursor/plugins](https://github.com/cursor/plugins) and anthropics/skills. Skill quality and security governance is becoming its own category.
- Multi-agent orchestration and phone/desktop monitoring are both hot: SoduWork, t3code, orca, LoopForge and [nightly-labs/openbot](https://github.com/nightly-labs/openbot), plus tim-agent, Fuyu and agent-hud-open. Claude Code and Codex are the default hosts for nearly all of these tools.
- Spikes at mature repos (superpowers, firecrawl, n8n, awesome-mcp-servers at +307 against a 7-day average of 83, appwrite at +252 against 55) have no visible source in the data, and I didn't look.
- The data also contains a DeepSeek Harness (dsh) ecosystem: deepseek-harness itself at 284,124 stars, plus dsh-desktop (+229), [helloHub1212/dsh-windows-mcp](https://github.com/helloHub1212/dsh-windows-mcp), dsh-our-free-model and others.
