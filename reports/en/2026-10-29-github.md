## Agent Context: what features people are building

**Theme 1: Design taste / anti-AI-slop skills**
- Problem: coding agents produce generic UI and copy. These skills give them design vocabulary, aesthetic constraints and in-browser self-checks. This is the fastest-growing group among skills today.
- [pbakaus/impeccable](https://github.com/pbakaus/impeccable) · ⭐94,634 · +2,787/day: gives a coding agent a design vocabulary (steering words like polish and bolder, review words like critique and audit). Yesterday's +2,543 was a 30-week peak. 38 straight days of high growth.
- [Nutlope/hallmark](https://github.com/Nutlope/hallmark) · ⭐41,712 · +1,490/day: anti-AI-slop design skill for Claude Code, Cursor and Codex. Over the past 14 days it went from roughly +60–100/day to 2,683, with 8 straight days of high growth.
- [Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill) · ⭐105,224 · +1,074/day: adds art direction, reference images and browser checks to an agent, replacing generic AI-looking pages.

**Theme 2: Long-term memory**
- Problem: remember what the agent did across sessions and feed it back into context.
- [vectorize-io/hindsight](https://github.com/vectorize-io/hindsight) · ⭐56,053 · +1,429/day: "Agent Memory That Learns." Daily gains were mostly 280–440 over the past two weeks, then jumped to 1,262 yesterday. The data doesn't show why.
- [thedotmack/claude-mem](https://github.com/thedotmack/claude-mem) · ⭐104,363 · +445/day: captures everything the agent does in a session, compresses it with AI, and injects relevant context into future sessions.
- [volcengine/OpenViking](https://github.com/volcengine/OpenViking) · ⭐41,124 · +103/day (Trending daily basis): combines agent memory, knowledge RAG and skills into one context database.

**Theme 3: Codebase indexing / knowledge graphs / local search**
- Problem: let an agent understand a whole codebase and its docs without grepping.
- [Graphify-Labs/graphify](https://github.com/Graphify-Labs/graphify) · ⭐138,387 · +895/day: uses local, deterministic AST parsing to turn code, docs, SQL, configs and PDFs into a queryable knowledge graph. Every edge is explained, and no vector store is needed.
- [xerj-org/xerj](https://github.com/xerj-org/xerj) · ⭐17,510 · +228/day: a single Rust binary offering hybrid BM25 + vector search, code search, agent memory and RAG. It is Elasticsearch-API compatible and ships its own MCP server.
- [NVIDIA/auto-ontology](https://github.com/NVIDIA/auto-ontology) · ⭐582 · +99/day: builds a semantic graph reasoning layer over data, for deterministic query generation and more explainable context retrieval.

**Theme 4: Token cost / compression**
- Problem: cut the token spend of coding agents.
- [JuliusBrussee/caveman](https://github.com/JuliusBrussee/caveman) · ⭐115,988 · +275/day: makes the agent talk like a caveman, claiming 65% fewer tokens. Also available as a proxy.
- [cheaper-inference/OmniRoute](https://github.com/cheaper-inference/OmniRoute) · ⭐82,471 · +360/day: free AI gateway with one endpoint for 375 providers and quota-aware automatic fallback. RTK+Caveman compression is claimed to save 15–95% of tokens. 123 straight days of high growth.

## Observations

- Skills are shifting from teaching agents to do things toward controlling the quality of what they produce. Anti-AI-slop design skills (impeccable, hallmark, taste-skill) and security audits (Cloudflare, NVIDIA SkillSpector) are today's two fastest lines. impeccable's 7-day average of 1,295 against a 28-day average of 742 means it is accelerating, not fading.
- Companies are publishing their own skill or methodology repos: Google's elephant-goldfish-model (+1,313/day), Cloudflare, NVIDIA's SkillSpector and auto-ontology, Microsoft's TokenEconomizer, MiniMax's mcode-stack, JetBrains' thinkrail. The Google, MiniMax and Microsoft repos have few stars so far, and all three are 1–2 day bursts.
- Two ecosystems are clustering. One is DeepSeek Harness: the core repo has 265,614 stars, and dsh-our-free-model, dsh-desktop, DS-Bot and dsh-baton also carry the dsh-plugin tag. The other is agent reverse engineering: morluto/rea has 406,246 stars, with at least four awesome lists downstream and the counter-project bla. These notes only report the tags and repos seen in the data, not any relationship between the two.
