## 1. Agent Context: what features people are building

Lets agents query a graph instead of reading a whole repo or relying only on vector search. That saves tokens and makes results easier to explain. After NVIDIA's entry, graph projects have the steepest context curve today.

- [NVIDIA/auto-ontology](https://github.com/NVIDIA/auto-ontology) · ⭐8,600 · +1,829/day: builds a semantic-graph reasoning layer over data, with deterministic query generation and better context retrieval. Created in April; daily gains were only 20 to 30 until Nov 3 (last 4 days 25 → 392 → 2,322 → 2,465 → 2,072).
- [Graphify-Labs/graphify](https://github.com/Graphify-Labs/graphify) · ⭐143,371 · +557/day: turns code, docs, SQL schemas, configs and PDFs into a queryable knowledge graph. Parsing is local and deterministic (AST), every edge is explainable, no vector store. 20 straight days of high growth.
