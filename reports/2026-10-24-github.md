## 四、观察

- **安全方向是 Skill 形态里最强的一类。** `cloudflare/security-audit-skill`（+2177）、`Claude-Red`（+641）排在 Skill 增速前列。`NVIDIA/SkillSpector`（+142）则提醒大家：Skill 本身也要先扫描再安装。
- **Agent 隔离与运行时从单点工具变成一组产品。** `OpenShell`、`sandbox-runtime`、`orca`、`herdr` 同时上榜。沙箱走 OS 级、轻量、不要容器的路线，管理层走"一批 Agent 并行"的路线。
- **"让编码 Agent 做非代码产出"成为新仓库的集中主题。** 视频（`lemo-opuscar`、`openfilm`、`vvv`）、音频（`earshot`）、CAD（`solidcraft`）、真实设备（`esp32-iphone-agent`）都在今天的新仓库榜上，共同点是以 Skill 或 MCP 形式接入现有 Agent。
- **dsh 生态继续主导流量。** `deepseek-harness` 总星 260,244，`rea`、`archify`、`ruflo` 等都带 `dsh-plugin` 相关标签，新仓库榜首的 `dsh-our-free-model` 日增 +2120。不过其中不少增长来自"免费模型"的吸引力，不一定代表上下文能力本身的进步。
