## 热度榜：Agent Context 精选

### [Who Remembers What? Multi-Granularity Memory Extraction for Multi-User, Multi-Agent Interaction](https://arxiv.org/abs/2611.10439)
- 热度：HF 👍8（入榜 1 天，新增 +1）；无 X 提及；无代码仓库。
- 问题：自进化 Agent 之间共享经验时，没有机制决定每条经验谁能受益、哪些信息必须保密。
- 方法：MixUA 把各用户-Agent 的轨迹提炼成 lesson，再按受益对象和可披露范围分到「用户-Agent 对 / 用户 / Agent / 全局」四种作用域。评测用新基准 CrossLearnBench，它把已有 Agent 任务和用户偏好、隐私探针配在一起，检查私有事实会不会漏进别人可读的记忆，设置为 5 个用户、7 个 Agent。
- 结论/意义：通过率比无记忆最多高 16 点，比单一全局记忆高 5 点，最多保留 90% 已声明偏好，隐私探针在禁止范围内被找到的比例至多 0.02%。亮点在记忆分作用域和隐私，不只是检索准确率。

### [Experience-Handoff Reinforcement Learning for Recursive Self-Improvement](https://arxiv.org/abs/2611.16409)
- 热度：HF 👍5（入榜 2 天，新增 +4）；无 X 提及；代码 [doyoungkim-ml/ehrl](https://github.com/doyoungkim-ml/ehrl) ⭐3。
- 问题：现有 harness 会反思或压缩经验并传给后续 rollout，但 playbook 这类「传递物」的生成本身没有被学习。
- 方法：固定 Agentic Context Engineering（ACE）harness，训练同一个模型分别扮演 action generator、insight reflector、playbook curator。候选经验产物按它对后续 actor rollout 的下游效果来评估，三个角色一起优化。
- 结论/意义：在多个 agentic 基准上，held-out 表现高于基线方法。训练不仅要优化当前动作，也要优化后续 rollout 会继承的、模型自己写的经验。

### [HiVe-Mem: Interleaving Horizontal Memory Expansion and Vertical Evidence Composition for Multimodal Agents](https://arxiv.org/abs/2611.12872)
- 热度：HF 👍4（入榜 2 天，新增 +1）；无 X 提及；代码 [ViktorAxelsen/HiVe-Mem](https://github.com/ViktorAxelsen/HiVe-Mem) ⭐0。
- 问题：多模态 Agent 的交互历史越来越长，基于压缩记忆的语义检索容易漏掉相关记忆，也不能适应不同 query 对证据形式的不同需求。
- 方法：横向，用文本和视觉锚点把记忆片段组织成关系图，从语义检索得到的种子出发，扩展到相关邻居。纵向，每条记忆保留摘要、caption、grounded 视觉视图、原图、交互历史等多种证据形式，由轻量可训练 selector 为每条记忆单独选证据子集。
- 结论/意义：在 3 个多模态记忆基准上，各基础模型均提升，token 消耗比最省的竞争多模态基线低约 90%。

### [Can LLM Agents Organize Their Own Memory?](https://arxiv.org/abs/2611.11929)
- 热度：HF 👍0（arxiv 来源，入榜 5 天）；无 X 提及；代码 [Qi202/SoMem](https://github.com/Qi202/SoMem)（星数数据未提供）。
- 问题：现有记忆依赖预定义记录和固定组织规则，难以适应变化的任务。
- 方法：SoMem 把记忆存成互相链接的普通文档。Agent 自己决定摘要什么、如何分组、何时修订主题，每条摘要都链回原始交互作为证据。运行时校验更新，并自动派生时间、关系、近期记忆视图。查询时 Agent 自己选择搜什么、读什么，沿链接回看原始证据。
- 结论/意义：在 LoCoMo、BEAM-100K、LongMemEval-S 上分别比最强基线高 2.66、3.10、2.00 个百分点，构建出的记忆可跨模型复用。

### [MIRIX-2.0: Multi-Agent Memory System](https://arxiv.org/abs/2611.12068)
- 热度：HF 👍0（arxiv 来源，入榜 5 天）；无 X 提及；摘要称代码公开，数据里没有链接。
- 问题：长期记忆里，参数化记忆要训练，合并会永久丢细节，全留记录又让存储越来越大。
- 方法：6 个带类型的记忆 Agent 保存完整记录作为权威来源，用 provenance 超图索引情景和语义记录，n 元 frame 引用来源行。检索在明确预算下运行，检索量不随历史增长。AutoDream 在写入路径之外合并重复锚点（不改写记录），并把任务会话提炼为 skill。
- 结论/意义：LoCoMo 91.4%，LongMemEval-S 72.6%（领先最强基线 14.3 点）；MetaClaw-Bench 49.2%，对比 MetaClaw 技能库的 44.0%。5 个 QA 基准中有 4 个最准。关闭 AutoDream 时，5 个计时基准上都比 HyperMem 快。

### [Compaction, decay and reinforcement in a two-tier conversational memory: a paired evaluation against retrieval-augmented generation](https://arxiv.org/abs/2611.09807)
- 热度：HF 👍0（arxiv 来源，入榜 6 天）；无 X 提及；无代码仓库。
- 问题：对话 Agent 该保留原始转录再检索（RAG），还是把每轮压缩成原子事实再检索？
- 方法：在 LoCoMo 的 1,985 个问题上，用同一生成器、同一评判、同一存储做配对比较，并用 McNemar 精确检验分歧的 512 题。
- 结论/意义：在可比工作报告的 4 个类别上，压缩 71.4% 对 RAG 64.6%，领先 6.8 点（p = 5.5e-08），prompt token 少 34%。算上对抗类共 5 类后，领先缩到 2.0 且不显著，因为 RAG 在对抗类领先 14.6。压缩保留事实断言、丢掉措辞，答案是「值」时占优，答案要求原话措辞时落后。

## 研究趋势观察
- 记忆系统的重点从检索准确率转向治理和边界：MixUA 管作用域与隐私，[MemoryDojo](https://arxiv.org/abs/2611.09721) 管投毒风险（155 条多会话长程轨迹、4 个领域、5 种记忆系统，所有记忆系统都会被投毒，影响差异很大；arxiv 来源，点赞数据为 0）。
- 压缩与保留原文的取舍更清楚：[2611.09807](https://arxiv.org/abs/2611.09807) 显示压缩在答案是值时赢、在答案要原话时输；SoMem 的摘要始终链回原始交互；MIRIX-2.0 以完整记录作系统记录，检索有预算。三者在设计上都没有丢掉原文。
- 经验和技能被当作可学习对象：EHRL 训练 playbook 的生成；[From LoRA to Language](https://arxiv.org/abs/2611.09454) 研究把 skill 文档编进 LoRA 后能否写回文本（Executing Writer 恢复 39-44% 关键指令；ALFWorld 上 Llama-3.1-8B 从 5% 升到 55%；arxiv 来源，点赞为 0）。
- 长程评测与 harness 简化：Infrathon 显示评测时长影响结论；JustRUA 显示精简 harness 加完整历史就能大幅提分。
