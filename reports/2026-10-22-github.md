## 一、Agent Context 方向：大家在做什么特性

### 1. 上下文压缩 / 工具输出裁剪 / token 成本
解决工具输出、日志、RAG 片段挤占上下文窗口和 token 开销的问题。Headroom 与 context-mode 同时在榜，方案都是在内容进入模型前先做压缩或沙箱化。

- [headroomlabs-ai/headroom](https://github.com/headroomlabs-ai/headroom) — ⭐77,537 · 今日 +552 — 在内容到达 LLM 前压缩工具输出、日志、文件和 RAG 片段，以库、代理或 MCP server 形式提供。项目称对编码 Agent 可省约 20% token，对 JSON 可省 60–95%。
- [mksglu/context-mode](https://github.com/mksglu/context-mode) — ⭐31,806 · 本周 +2,968 — 将工具输出放进沙箱（称减少 98%），持久化会话记忆，并通过 MCP + hooks 覆盖 17 个平台。
- [JuliusBrussee/caveman](https://github.com/JuliusBrussee/caveman) — ⭐114,346 · 本周 +2,419 — 让 Agent 用"原始人式"精简表达，称可减少约 65% token，形态是 skill + 代理。
- [DietrichGebert/ponytail](https://github.com/DietrichGebert/ponytail) — ⭐173,066 · 今日 +1,949 — 用提示词让 Agent 像"最懒的资深工程师"，尽量少写代码，属于行为约束类。

## 四、观察

1. **Context 工程从"提示技巧"走向"基础设施"**：压缩（Headroom、context-mode）、检索（Graphify、xerj、jevgrep）和记忆（ai-memory、engram、agent-beacon）三层同时出现在榜上，多数以 MCP、hooks 或 skill 形式接入，并强调本地运行。
2. **技能 / 插件标准在向跨 harness 收敛**：多个项目在描述里同时列出 Claude Code、Codex、Cursor、Gemini CLI 等，官方目录（Anthropic、Cursor、Vercel）本周增量不小。这类项目更像分发层，不再绑定单一 Agent。
3. **围绕 Agent 的"管理层"工具升温**：Orca、harp、coucou、worktrunk、magpie 解决的是并行多 Agent、批准通知、worktree 隔离和模型切换。这说明使用者已在同时运行多个 Agent，瓶颈从单个 Agent 能力转向调度和注意力。
4. **安全与垂直领域 Agent 出现明显热点**：security-audit-skill 今日增量最高，pentagi、ARTEX、rea 及一批逆向工程项目同时走热。需要注意，今日数据缺少历史快照，也无法核实 rea 的异常增量，这些判断只反映当日榜单，不代表持续趋势。
