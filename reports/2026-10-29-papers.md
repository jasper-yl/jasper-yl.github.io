## 🔥 热度榜：Agent Context 精选

### [The Trinity: Capability-Driven Recursive Self-Improvement for Multimodal Agents](https://arxiv.org/abs/2610.36077)
- 热度：HF 👍543（入榜 1 天，新增 +236，首次出现时 307）；无 X 提及；代码 [InfRec-Cardinal/The-Trinity](https://github.com/InfRec-Cardinal/The-Trinity) ⭐26
- 问题：可验证环境的构造成本高，人工迭代 Harness 跟不上任务的多样性。
- 方法：设 Creator、Explorer、Evolver 三个角色。Evolver 依据已验证的执行轨迹，把任务按共享的能力需求重组为分层「能力树」；Creator 为同一节点下的异构任务抽象出简化且可验证的模拟世界（Capability-Driven Real2Sim2Real）；Explorer 沿能力树通过选择性继承进化可复用的能力模块，形成 Harness 树。Capability-Aware Harness Router 只用公开任务信息，从树中挑选模块配置。
- 结论/意义：进化后的 Harness 在 28 个训练基准上平均提升 34 分，在 18 个未见基准（含 2 个真实具身任务）上提升 26 分。今天热度最高的 Harness 设计论文。

### [Memory Tax: Dissecting the Net Value of Agent Memory](https://arxiv.org/abs/2610.34073)
- 热度：HF 👍149（入榜 1 天，新增 +81）；X 提及 1 次，[@omarsar0 推文](https://x.com/omarsar0/status/2115098954799169970)（❤487）；代码 [hexuan21/MemoryTax](https://github.com/hexuan21/MemoryTax) ⭐10
- 问题：专用记忆系统相对直接检索原始历史，净价值是正是负。
- 方法：跨多个基准和骨干模型大规模评测，以朴素 RAG 为参照，把记忆的净价值拆成 memory benefit（增益）和 memory tax（代价）。代价来自记忆过程改变了原始信息的组织方式：重组事实、提炼偏好的同时，也可能删除或模糊证据。论文再从系统侧和评测侧分析代价的成因，并推广到更多场景。
- 结论/意义：许多专用记忆系统在不少情况下不如朴素 RAG，净价值为负。与今天的 HABIT-Bench、MemPilot 构成一组记忆主题，其中它有 X 传播，话题度最高。

### [HABIT-Bench: Evaluating Habit Induction from Longitudinal Weak Evidence in Agent Memory](https://arxiv.org/abs/2610.24520)
- 热度：HF 👍83（入榜 1 天，新增 +5）；代码 [LUMIA-Group/habit-bench](https://github.com/LUMIA-Group/habit-bench) ⭐4
- 问题：只保留过往交互，不能保证 Agent 从弱证据中推断出用户习惯并恰当使用。
- 方法：基于任务型对话数据和受控的习惯图，构造跨数百个会话的合成用户历史，覆盖餐饮、金融、软件、旅行。题目为四选一，包含临时例外、习惯变化、用户未接受的建议，抽样题经人工复核。共评测 8 种记忆方法。
- 结论/意义：最佳记忆方法在四个领域的宏平均准确率仅 33.61%，即使直接给出标注证据，表现仍有限。

### [MemPilot: Orchestrating On-Demand Multimodal Memory Curation for LLM Agents](https://arxiv.org/abs/2610.06830)
- 热度：HF 👍41（入榜 7 天，新增 +5）；代码 [ViktorAxelsen/MemPilot](https://github.com/ViktorAxelsen/MemPilot) ⭐7
- 问题：多数记忆系统与查询无关地构建记忆，预处理有浪费，还会丢掉后来才变重要的细节。
- 方法：用 RL 训练多步策略，每步在「从查询无关的记忆中检索」和「把原始多模态历史交给异构 LLM/VLM 做查询相关的整理」之间选择。策略联合控制证据量、整理指令、模型选择和视觉访问。训练时按目标分解优势，并用基于前缀的边际效用估计做信用分配。
- 结论/意义：在 5 个多模态记忆基准上，不同偏好下的性能—成本—延迟前沿，比现有权衡感知基线更宽。

### [DeLoop: Repeated Actions as Self-Supervision for Long-Horizon Agents](https://arxiv.org/abs/2610.19376)
- 热度：HF 👍33（入榜 7 天，新增 +16）；代码 [cskyl/deloop](https://github.com/cskyl/deloop) ⭐3
- 问题：长任务 Agent 会重复发出相同的工具调用并得到相同的观察（loop），历史被压缩后更常见。
- 方法：以 Agent 自己 rollout 里的循环动作为负例，以同一 rollout 中之后第一个非循环动作为正例，做 DPO。不需要任务奖励、标准答案或 LLM 评判。
- 结论/意义：在 CodeGym 压缩设定下，Qwen3-8B 含循环任务的占比从 57.3% 降到 6.1%，步数约为原来的三分之一；Qwen3-32B 成功率从 37.7% 升到 44.8%。直接对应上下文压缩后的行为退化。

### [DeltaStreamer: Towards Human-Like Agentic Streaming Video Understanding](https://arxiv.org/abs/2610.19849)
- 热度：HF 👍38（入榜 6 天，新增 0）；代码 [BBBBchan/DeltaStreamer](https://github.com/BBBBchan/DeltaStreamer) ⭐87
- 问题：流式视频要在不知道未来问题的情况下保留证据，压缩历史会模糊事件转换、丢失细节且无法恢复。
- 方法：查询到来前持续观察，把视觉变化显式记入结构化的 change-aware 记忆。查询到来后，由查询驱动的规划器决定所需证据，引导记忆检索和对历史帧的定向回放。
- 结论/意义：OVO-Bench 66.07%，StreamingBench 59.53%，优于代表性流式方法。

### [DLite: History-free Speculative Decoding for Agentic AI](https://arxiv.org/abs/2610.23787)
- 热度：HF 👍36（入榜 6 天，新增 +3）；代码 [SJTU-DAI-Sys/DLite](https://github.com/SJTU-DAI-Sys/DLite) ⭐49
- 问题：Agent 场景下长且不断演化的上下文，使现有草稿模型的接受长度最多下降 80%，维护历史 KV cache 的系统开销也大。
- 方法：直接复用目标模型的上下文隐藏状态，只做局部推测预测，不显式维护历史上下文；再用轻量顺序头恢复块内因果依赖，并配两阶段训练。
- 结论/意义：接受长度 2–6，比 SOTA 推测解码方法 DSpark 最多快 70%。

## 研究趋势观察
- Harness 成为一等优化对象：The Trinity、HarnessPro、Harness Scaling、SERA 都在进化或缩放 Harness，Self-Evolving Harness（见 10-25 日报，仓库 [zgcagi/Harness-RSI](https://github.com/zgcagi/Harness-RSI) ⭐387）提供了理论框架。
- 记忆研究从造系统转向算净价值与做评测：Memory Tax 对比朴素 RAG，HABIT-Bench 测习惯推断，MemPilot 按查询按需整理记忆。MMEnterprise-Bench（👍33）也显示，提高检索预算只提升证据召回，不一定提升答案准确率。
- 上下文压缩与多会话成为训练问题：DeLoop 处理压缩后的循环；Mosaic（👍63，首现于 10-23，点赞未再增长）针对上下文压缩和子 Agent 分叉做多会话 RL。
- 工程侧呼应：[Tongyi-MAI/OpenGCUA](https://github.com/Tongyi-MAI/OpenGCUA) ⭐441 与 [InternLM/Intern-Decision](https://github.com/InternLM/Intern-Decision) ⭐775 星数较高，Harness 与开源栈受关注。
